# Skill 术语

> 只收 skill 自有词；项目领域词进项目的 `docs/glossary.md`。
> 一个词只在这里定义一次；完整词表后续可补，先收最容易混的。

| 词 | 所指 | 不指 |
| --- | --- | --- |
| **复核** | 一个看不到本会话的独立 agent：复述 / 找缺口 / 判定 | 自己复读、脚本检查 |
| **核对** | 文档与代码 / 记录 / 状态逐条摊开比对（E-5） | 文档内部是否清晰 |
| **验收** | 可执行证据（测试 / fixture / 断言 / 命令） | 复核通过、作者说没问题 |
| **检查** | 脚本做的结构性扫描 | 语义复核 |
| **未接入** | `scripts/` 没投进项目 | 已通过 |
| **未复跑** | 脚本在，但只列未执行 | 已通过 |
| **未复核** | 计划过复核但跳过 | 已通过 |
| **快照** | 项目侧的只读副本；skill 是源 | 工作副本 |
| **工作副本** | 项目侧可编辑的文件；skill 模板是上游默认 | 快照 |
| **索引** | 文档级目录，上指下 | 条款引用 |
| **引用** | 条款级，下指上，只写稳定代号 | 文档目录 |
| **一处成文** | 同一规则只有一个正文 | 每处都写全 |
