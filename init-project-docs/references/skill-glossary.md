# Skill 术语表(本 skill 自有词)

> **用途:** 本 skill 的许多词是**常见词 + 专指**;按通用义读会偏。本表给出「本 skill 所指 / 不指什么 / 定义位置」。
> **边界:** 本表只收 skill 自己的术语;**项目领域词**进项目的 `docs/glossary.md`,不在这里重复。
> **规则:** 与通用义冲突时以本表为准;首次出现给一句限定或指向定义处;新增 / 改名术语时同步本表与 `SKILL.md` 的「术语速查」。

## 一、时间轴与记忆

| 词 | 本 skill 所指 | 不指什么(易混) | 定义 / 展开 |
|---|---|---|---|
| **历史 / 历史桶** | 项目记忆里**决策记录**的那一桶:ADR、reviews、git;内容只增不改,存在按寿命裁剪(升格 / 退役),只作方向 | 不是 git 的全部历史;不是"过去发生过的所有事";不等于永久保留 | `temporal-model.md`;E-4 |
| **当下 / 当下桶** | **现状与约束**的那一桶:L1–L4、glossary;事实、不变量、术语;不保留旧陈述 | 不是"当前时刻",也不是整个项目 | `temporal-model.md` |
| **未来 / 未来桶** | **方向与开放问题**的那一桶:计划、候选、开放问题;必须带状态 | 不是产品路线图的同义词;不是"以后再说"的垃圾箱 | `temporal-model.md` |
| **记录** | 历史留档的统称:决策记录(ADR)/ 复核记录(reviews) | 不是现状事实源;不能拿来回答"现在是什么";两者保留规则不同;游标不是记录 | `temporal-model.md`;E-4 / E-5 |
| **决策记录(ADR)** | 单个决策**过程**的载体:背景 / 被拒方案 / 选择 / 后果;是工作台,不是档案 | 不是现状文档;不是永久档案;不是每条决策都该有的容器 | E-4 |
| **复核记录(reviews)** | teach-back / 对账的发现与判定留档 | 不是决策记录;不是验收证据的替代品 | E-5 |
| **游标(`.last-review`)** | 只记录"复核看到哪个提交"的状态(SHA + 日期) | 不是历史记录;不参与升格 / 退役 | E-5 |
| **升格** | 把仍成立的理由从记录搬进当下正文(`[为什么]` / 不变量 / 危险清单),然后记录退役 | 不是把 ADR 复制进文档;不是保留摘要 | E-4 |
| **退役** | 记录移出工作区,字节留在 git;须有正面证据(升格 / 前提消失 / 作者拍板) | 不是删除;不是移进 `archive/`;不是压缩;不是"答不出就退" | E-4 |
| **退役候选** | 对账中三问答不出、但尚未取得正面证据的记录;登记待作者拍板 | 不是 `expired`;不是可自动退役 | E-4 |
| **过期(expired)** | 记录的前提**有证据地**消失,没有继任决定 | 不是 `superseded`(有继任决定);不是"退役候选"(候选不改 `status`) | E-4 |
| **唯一正文归属**(旧称"正典") | 某类定义 / 规则**只在一处**成文的那一段;别处不写摘要,引用时只给**稳定代号**(如 `D-14`) | 不是"canonical version"这种泛称;不是"最早的那份" | `temporal-model.md`;E-1 / E-3 |
| **沉淀侧** | 把对话内容固化为项目记忆(历史 / 当下 / 未来)的那一半职责 | 不是"对话技巧"(怎么提问 / 质疑 / 去模糊) | `SKILL.md` 顶部 |
| **回灌** | 把下游实践中的可泛化经验写回上游 skill(本 skill → `seeding-skills`) | 不是数据回填 / 迁移;不是把项目内容搬进 skill | `SKILL.md` 顶部;`RESEARCH-BACKLOG.md` |
| **候选(待否决)** | 一种**状态**:还没有被接受的提案;未接受的一律登记未来桶 | 不是落点,不是结论;不能静默转正 | `SKILL.md`「候选」段;`temporal-model.md` |
| **方向草案** | 未收敛时 L1 概述的「现状 / 方向草案」双段;只有方向半段带状态 | 不是普通方向陈述;不是允许把计划写成事实 | `SKILL.md` Step 3;`temporal-model.md` |

## 三、对账、复核、验收(四者不互换)

| 词 | 本 skill 所指 | 不指什么(易混) | 定义 / 展开 |
|---|---|---|---|
| **对账** | 把文档与代码 / 记录 / 状态**逐条摊开比对**,列差异与缺口;可脚本可人工,改代码前与版本级都用 | 不是会计对账;不是"只在事后做" | E-5;`tooling.md` |
| **复核** | 派一个**看不到本会话**的独立 agent,对文档做复述 / 缺口 / 判定 | 不是自己复读一遍;不是脚本检查 | `teach-back-verifier-prompt.md`;`review-panel.md` |
| **验证 / 验收** | 用**可执行证据**(测试 / fixture / 断言 / 命令)证明行为 | 不是"复核通过";不是"作者说没问题" | `verifying-n2.md`;`temporal-model.md` |
| **检查** | 脚本做的**结构性 / 可证伪**扫描(死链、引用、重复定义等) | 不是语义复核;不是"检查器过了 = 文档对了" | `tooling.md` |
| **镜头** | 一个**独立复核视角**,由一个独立验证者执行 | 不是相机镜头,也不是 UI panel | `review-panel.md` |
| **多镜 panel** | 多个互不可见的镜头各判一遍,协调者合并去重 | 不是"多跑几次同一个镜";不是 UI 面板 | `review-panel.md` |
| **派发包(dispatch packet)** | 发给一个镜头的一组文件:文件清单 + 镜头附言 + 探针 + 输出要求 | 不是整个仓库;不是会话记录 | `review-panel.md` |
| **镜头附言(addendum)** | 在基座 prompt 上追加的该镜检查项 / 输出差异 | 不是另写一份完整 prompt | `review-panel.md` |
| **MANIFEST** | 派发包的清单:日期 / 文件 / 镜头 / 探针 / 输出路径 | 不是构建产物清单 | `review-panel.md` |
| **阻断 / 非阻断 / 需人拍板** | 复核判定的三类缺口:必须补 / 建议 / 答案在人手里 | 不是"通过 / 不通过"的两档;需人拍板不是失败 | `teach-back-verifier-prompt.md` |
| **复核通过** | 文档达到本单元达标线,**只说明内部一致** | 不证明断言在现实中为真 | `teach-back-verifier-prompt.md`;`SKILL.md` 验收 |
| **校准 / 校准探针** | 用**已知缺陷**验证一个镜头 / prompt 能不能红;探针 = 预埋的已知缺陷 | 不是仪器校准;不是代码探针 | `calibration-guide.md` |
| **基线** | **必须带限定语**:校准基线 = 已知答案的对照文档;文档基线 = `last verified` SHA;性能基线 = 已测的性能参考;分档基线 = novelty 起评点 | 不要用裸"基线"兼指这几种 | `calibration-guide.md`;`tooling.md`;`templates/glossary.md` |
| **快照** | **必须带限定语**:现状快照 = 当前事实;历史快照 = reviews / ADR 留档;数据快照 = 固定输入副本 | 不要用裸"快照"兼指这三者 | E-1;`verifying-nonfunctional.md` |
| **冻结** | **必须带限定语**:冻结计数 = 文档里固定的数字;冻结期望 = 已批准的 golden fixture;冻结画面 = 固定的渲染状态 | 不是"代码冻结 / 发布冻结" | `teach-back-verifier-prompt.md`;`verifying-n2.md` |
| **文件白名单** | 允许验证者读的 N 个文件清单 | 不是安全 allowlist;不是"所有文件都能读" | `teach-back-verifier-prompt.md` |
| **最小独立模拟器** | 按文档规则**从零写一个临时实现**,复现计数 / 阈值 / 守恒等式 | 不是替身环境;不是产品代码 | `teach-back-verifier-prompt.md` |
| **未接入 / 未复跑** | 未接入 = `scripts/` 未拷入;未复跑 = 脚本在但这次只列未执行 | 都不是"已通过";不是"脚本失败" | `tooling.md` |

## 五、无上下文理解测试(改动高频词时跑)

1. 新开一个 agent,**只给 `SKILL.md`**,不给 references;明确禁止读其它文件。
2. 固定词表至少含:历史 / 当下 / 未来、契约级变更、对账、复核、镜头、未接入、未复跑、待填件、就地读件、基线 / 快照 / 冻结、正文归属 / 拍板人、主型 / 副型、文件白名单 / 模拟器 / 探针。
3. 让它逐词给定义,并标「文件明确给出 / 从上下文推断 / 猜的」。
4. **判据:** 出现「猜的」或与本表不一致 → 在 `SKILL.md` 首次出现处补一句限定,或把该词加进「术语速查」。不追求满分,只追「不再 confidently wrong」。
5. 记录:首轮 / 改后各一次;可放 `.calibration/`(本地,不入库);只比「猜的」数量与偏离项。

## 六、首轮术语测试基线(2026-10-19)

14 组词里,只有 2 组在 `SKILL.md` 有明确定义;5 个词(`基线 / 快照 / 冻结 / 正典 / 模拟器`)在 `SKILL.md` 根本没出现;其余靠猜。典型偏离:

- **对账** → 被读成"纯事后 / 补齐动作";实际改代码前也做对账。
- **模拟器** → 被读成"替身环境";实际是"按文档规则从零写临时实现复现数字"。
- **正典** → 被读成泛化的 "canonical version";实际指"某类定义 / 规则只在一处成文的那一段"(旧称,今用「唯一正文归属」);它不指"ADR 的角色"。
- **主型 / 副型** → 只看到标签,判据不明;实际主型决定验收、副型只影响写法。

本轮修复 = `SKILL.md` 顶部「术语速查」+ 本表 + 首次出现限定 + 三个改名(考古层 → 存档层、文档考古 → 全量文档对账、正典 → 唯一正文归属)。**改后复跑(同词表):14/14 显式**;两处粒度不足(`拍板人` 未写谁有资格、`冻结` 只给例未给动作)已在速查表补为「作者 / 用户」与「冻结计数 / 期望 / 画面的定义」。用同一词表继续跑,后续目标是保持 14/14,而不是增加词表长度。
