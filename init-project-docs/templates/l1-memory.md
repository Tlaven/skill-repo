# L1 记忆文件(项目根)

> 复制到项目根,按宿主命名(见下表)。
> **L1 只放项目记忆**:作者裁定 / 当前约束 / 命令 / 活文档索引 / 开放问题。
> **方法论不在 L1**:三段式 / 4 层 / novelty / 铁律 / 加载表在方法论就地读件（`docs-templates/methodology.md` 或项目已有的 `docs/templates/methodology.md`），只在写 / 改 / 审文档时读。
>
> | 宿主 | 文件名 |
> |---|---|
> | OpenCode / Codex / 通用 | `AGENTS.md` |
> | Claude Code | `CLAUDE.md` |
> | Cursor | `.cursor/rules/project.mdc` |
> | Windsurf | `.windsurfrules` |
> | GitHub Copilot | `.github/copilot-instructions.md` |
>
> **预算:** 行数是软预算，只警告、不阻断；超了先合并，或把细节移到活文档。
> **活文档清单:** `docs/.live`(一行一个路径);没列进去的 `docs/` 文档按历史 / 参考处理,不进日常加载。
> **最后验证:** `Last verified: <commit SHA>`(可选,一行)。
> **不写:** 日期、文档版本号、变更史、旧状态。
> 若未拷入 `scripts/`,标 `scripts: 未接入`;命令按「未复跑」处理。
