# Core Code — L4 核心代码层(可选)

> **使用方式:** 仅在项目有"牵一发动全身"的核心代码时才创建本文件。
> 默认不要——简单项目三层(L1/L2/L3)够用,只有 core 重、不变量多的项目才需要 L4。
> 三段式:[是什么] / [为什么] / [不变量]

---

## 收录标准(先看这条)

只有满足下列**至少一条**的函数才进 L4:

- **高扇入公共依赖**:很多模块调用它(改签名/语义 = 全项目改)
- **架构骨架**:定义了项目的主要数据模型或抽象(改了等于重写)
- **不变量守护者**:函数隐含"调用前必须 X / 返回后保证 Y",违反就出隐蔽 bug
- **执行流入口**:故事从这里开始(主循环、事件分发、顶层 API)

**数量红线:** 中等项目 5~15 个,超过 20 个说明标准放松了。
判断尺度:**"改了会出大事"才进,不是"用了很多次"就进。**
