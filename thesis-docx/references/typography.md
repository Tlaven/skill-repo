# 中文字号与排版单位参考

## 字号对照表（号数 → pt）

| 中文号数 | pt | 常用场景 |
|---------|----|---------|
| 初号 | 42pt | — |
| 小初 | 36pt | — |
| 一号 | 26pt | — |
| 小一 | 24pt | 论文封面标题 |
| 二号 | 22pt | — |
| 小二 | 18pt | 论文大标题 |
| **三号** | **16pt** | **一级标题（小三）** |
| 四号 | 14pt | 二级标题 |
| 小四 | 12pt | **正文（最常见）** |
| 五号 | 10.5pt | 图题/表题/参考文献 |
| 小五 | 9pt | 页眉 |
| 六号 | 7.5pt | 脚注 |

注：有些学校用"小三"=16pt 作为一级标题字号，有些用"三号"=16pt。名称不同但 pt 值相同。

## 行距换算

| 行距设置 | 倍数对应值 | 常见用途 |
|---------|-----------|---------|
| 单倍行距 | 1.0 | 图题、表内文字 |
| 1.25 倍 | 1.25 | 标题、参考文献 |
| **1.5 倍** | **1.5** | **正文标准（多数学校）** |
| 双倍行距 | 2.0 | 论文草稿 |
| 固定值 20pt | exact 20pt | 某些学校要求精确行距 |

在代码中设置：

```python
safe.set_line_spacing(anchor, 1.5, rule="multiple")    # 1.5 倍
safe.set_line_spacing(anchor, 20, rule="exact")         # 固定 20pt
```

## 首行缩进

中文论文正文一般首行缩进 **2 字符**。2 字符 ≈ **当前字号 × 2**：

| 字号 | 2 字符缩进 |
|------|-----------|
| 12pt（小四） | 0.74cm |
| 10.5pt（五号） | 0.65cm |

## 单位换算

| 转换 | 公式 | 说明 |
|------|------|------|
| cm → EMU | `cm × 914400 / 2.54` | python-docx 内部长度单位 |
| EMU → cm | `emu × 2.54 / 914400` | |
| pt → EMU | `pt × 12700` | |
| EMU → pt | `emu / 12700` | |
| pt → 行距倍数 | `pt / 240` | rule="multiple" 时的换算 |
| 行距倍数 → pt | `multiple × 240` | |
| pt → 固定行距 | `pt × 20` | rule="exact" 时的换算 |

## Python 快速换算

```python
from core.utils import emu_to_cm, cm_to_emu
from core.utils import pt_to_emu

# cm ↔ EMU
emu_to_cm(914400)   # → 2.54 (1 英寸)
cm_to_emu(2.54)     # → 914400

# pt → EMU（不常用，仅供参考）
pt_to_emu(12)       # → 152400
```
