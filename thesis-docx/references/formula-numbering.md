# 公式编号与交叉引用检查

Agent 检查公式编号连续性和正文交叉引用的标准。

## 编号格式

### 标准格式
```
(X.Y)
```
- X = 章节号
- Y = 本章内序号（从 1 开始）

常见变体（应全文统一）：
- `(3.1)` — 最常见，括号包裹
- `式(3.1)` — 正文中引用时带"式"前缀
- `式3.1` — 无括号形式
- `(3-1)` — 短横线分隔

## 编号连续性

每章内编号必须连续：(3.1) → (3.2) → (3.3)，无跳号。

### 检查方法
1. 收集同章节所有公式的编号
2. 排序后检查是否从 1 连续递增
3. 跳号 = 有编号被跳过
4. 重复 = 同一编号出现多次

## 交叉引用检查

### 正文引用格式
```
"如式(3.1)所示"、"由式(3.2)可得"、"...（式3.3）"
```

### 常见错误

| 问题 | 示例 | 处理 |
|------|------|------|
| 正文引用了不存在的公式 | "如式(3.5)所示"但3.5不存在 | 修正编号或补充公式 |
| 公式存在但正文未引用 | 式(3.2)存在但无引用 | 要么引用它，要么删除 |
| 编号与章节不符 | 第2章出现公式(3.1) | 改为(2.X) |
| 编号格式不统一 | (3.1)和(3-1)混用 | 全文统一格式 |

## 公式前后文字

- 公式前应有引导语："如式(X.Y)所示"、"定义...如式(X.Y)"
- 公式后应有解释："其中，W表示权重矩阵，b为偏置向量"
- 公式不应孤立出现（前后无文字说明）

## 检查范围

- 所有 FormulaInfo 对象的 equation_number 字段
- 正文段落中 "式(X.Y)" 模式的引用
- 交叉比对：每个编号在公式列表和正文引用中应一一对应
