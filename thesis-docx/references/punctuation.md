# 标点符号规范

Agent 检查论文标点符号使用是否规范。

## 中英文标点区分

### 中文段落用中文标点

| 正确 | 错误 |
|------|------|
| 。（中文句号） | .（英文句号在中文段尾） |
| ，（中文逗号） | ,（英文逗号在中文句中） |
| ；（中文分号） | ; |
| ：（中文冒号） | : |
| " "（中文引号） | " "（英文引号） |
| （ ）（中文括号）  | (（英文括号后接中文） |

### 英文/数字用英文标点

英文句子内、变量名、URL 中使用英文标点。

## 常见问题

| 问题 | 表现 | 示例 |
|------|------|------|
| 中文段尾英文句号 | 一段纯中文，结尾用 `.` | `实验结果表明该方法有效.` → `实验结果表明该方法有效。` |
| 中英文引号混用 | 全文中英引号交替出现 | 上文用 `"\u201c"`，下文用 `"` |
| 括号中英混用 | 中文后用英文括号 | `卷积神经网络(CNN)` → `卷积神经网络（CNN）` |
| 英文逗号在中文句 | 造成间距不协调 | `A方法,B方法和C方法` → `A方法、B方法和C方法` |

## 检查重点

1. 中文正文段落末尾是否为 `。`（非 `.`）
2. 全文引号风格是否统一（`"\u201c\u201d"` 或 `""` 二选一）
3. 中文关键词/术语后的括号是否统一用中文括号 `（ ）`
4. 列表项末尾标点是否一致（句号 vs 分号 vs 不加）

## 可以不统一的例外

- 引用英文原文时保留原文标点
- 代码块内的标点不受此规范约束
- 数学公式中的标点属于公式内容
