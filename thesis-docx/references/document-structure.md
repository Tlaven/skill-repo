# 文档结构完整性

Agent 检查论文结构是否完整。

## 中文学位论文标准结构

一篇完整的中文学位论文应包含以下部分：

| 部件 | 必有 | 备注 |
|------|------|------|
| 封面/标题页 | ✅ | 含中英文题目、作者、导师、学校、日期 |
| 原创性声明 | ✅ | 需签名 |
| 中文摘要 | ✅ | 独立一页 |
| 英文摘要 | ✅ | 独立一页，与中文摘要内容对应 |
| 目录 | ✅ | 应为 Word 自动目录（域代码），非手打 |
| 正文各章 | ✅ | 按学校规范组织 |
| 参考文献 | ✅ | 独立一节 |
| 致谢 | ✅ | 独立一节 |
| 附录 | 可选 | 如有则应有编号，正文需引用 |

## 页码体系

| 区域 | 页码类型 | 说明 |
|------|---------|------|
| 前言部分（摘要、目录） | 罗马数字（i, ii, iii...） | 独立编号 |
| 正文（从第一章起） | 阿拉伯数字（1, 2, 3...） | 从 1 开始 |
| 附录 | 接正文编号或独立编号 | 按学校规范 |

检查：正文第一页页码是否为 1（不是续前言的罗马数字）。

## 目录检查

- 目录是 Word 域代码还是手打文字？
- 目录层级与正文标题层级一致
- 目录页码与正文实际页码对应

## 附录检查

- 附录编号用字母（附录 A、附录 B），不与正文章节号冲突
- 附录中的图表编号含附录标识（如图 A-1、表 B-2）
- 正文有对附录的引用（"详见附录 A"），否则说明附录可删除

## 检查方法

1. 检查章节树是否包含"摘要""Abstract""参考文献""致谢"等关键标题
2. 检查附录编号是否与正文章节号冲突
3. 检测正文中是否有对附录的引用
