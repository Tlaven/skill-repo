# 术语一致性检查

Agent 检查论文中关键术语是否一致使用的标准。

## 检查范围

### 技术术语
- 方法名、模型名、算法名（必须全文一致）
- 评价指标名（accuracy/准确率/精度 — 统一）
- 数据集名称（大小写、缩写一致）

### 概念术语
- 同义词不应混用：如果某处用"特征提取"、另一处用"特征抽取"→ 统一
- 缩写首次出现必须全称：`卷积神经网络（Convolutional Neural Network, CNN）`

## 常见混用

| 中文术语 | 易混用为 | 选定后全文统一 |
|---------|---------|--------------|
| 数据集 | 数据集合、样本集 | 选一个 |
| 准确率 | 精度、精确率、Accuracy | precision 和 accuracy 不是同一指标 |
| 损失函数 | 代价函数、目标函数 | 在非严格场景下可通用，但同论文应统一 |
| 训练集 | 训练样本、训练数据 | 选一个 |
| 测试集 | 验证集、Test set | 区分验证集和测试集 |
| 鲁棒性 | 健壮性、稳健性 | 选一个 |

## 检查方法

1. 提取正文中所有中英文混合词和缩写
2. 对每个词，检查全文出现的形式是否一致
3. 首次出现缩写时，检查前面是否有全称定义
4. 对高频中文术语，搜索同义表达，统一

## 不需要统一的情况

- 为避免重复的修辞性换词（"这表明/这说明/这意味着"）
- 引用他人工作时保留原文术语
- 通用词（"方法/方式/途径"在不产生歧义时可换用）
