# 图表编号规范

Agent 检查图表编号和交叉引用的标准。

## 编号规则

### 标准格式
```
图 X-Y    或者    图 X.Y
表 X-Y          表 X.Y
```

- X = 章节号（如第 3 章 → 3）
- Y = 本章内序号（从 1 开始）

示例：
- 第三章第一张图 → `图 3-1` 或 `Figure 3-1`
- 第三章第二张表 → `表 3-1` 或 `Table 3-1`

### 编号连续性

每章内编号必须连续：图 3-1 → 图 3-2 → 图 3-3，无跳号。

### 图题/表题位置

- 图题在**图下方**，居中
- 表题在**表上方**，居中

## 交叉引用检查

### 正文中的引用格式
```
"如图 3-1 所示"、"通过表 4-2 可以看出"、"...（图 5-3）"
```

### 常见错误

| 问题 | 示例 | 处理 |
|------|------|------|
| 正文引用了不存在的编号 | "如图 4-5 所示"但第四章只有 3 张图 | 修正引用或补充图表 |
| 图表存在但正文未引用 | 图 3-2 存在，正文无任何引用 | 要么引用它，要么删掉它 |
| 编号与章节不符 | 第 2 章出现了"图 3-1" | 改为"图 2-X" |
| 中英文混用 | "Figure 3-1"和"图 3-2"混用 | 全文统一 |
| 编号不连续 | 图 3-1, 图 3-3 但少了 3-2 | 重新编号 |

## 检查范围

- 扫描所有图片和表格的 caption，提取编号
- 扫描正文所有"图 X-Y"/"表 X-Y"/"Figure X-Y"/"Table X-Y"引用
- 交叉比对：每个编号要么两端都有，要么报错
