# 段落长度规范

Agent 判断"正文段落是否太长"的标准参考。

## 正常范围

| 段落类型 | 合理字符数 | 说明 |
|---------|-----------|------|
| 摘要段 | 150-400 | 全摘要通常一段，可达 800 |
| 正文段 | 150-500 | 超过 600 需关注 |
| 引言段 | 200-800 | 允许稍长 |
| 结论段 | 100-300 | 通常较短 |
| 图题/表题 | 15-80 | 一行标题 |
| 参考文献条目 | 50-200 | 每条文献 |

## 何时该拆分

以下情况应考虑拆分：

1. **单段超过 800 字符** → 几乎一定该拆
2. **一段讲了两个独立逻辑** → 句子间有"此外/另外/同时"等转折词衔接不同话题
3. **一段同时包含"做法"和"原因"** → "因此/所以/由此可见"前后的因果链太长
4. **阅读时需要回读才能跟上** → 主语频繁切换，每段只应有一个核心主语群

## 拆分策略

- 在句号后断开，不在逗号后断开
- 新段落承接上一段的逻辑，但应有自己的主题句
- 拆分后每段至少 80 字符，否则说明拆分过度
- 图题表题不参与段落长度检查

## 反例

| 问题 | 示例 | 处理 |
|------|------|------|
| 一段讲三个实验 | "实验 A 表明...此外，实验 B 的结果...另外，实验 C 也..." | 按实验拆分三段 |
| 因果链过长 | "由于...因此...从而导致...进而使得...所以..." | 在中间句号处断开 |
| 引入+结论放一段 | "本章提出...最终结果表明..." | 拆成方法段+结论段 |
