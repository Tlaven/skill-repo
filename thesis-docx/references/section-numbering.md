# 标题编号连续性检查

Agent 检查章节标题编号是否连续、格式是否统一的标准。

## 编号格式

### 常见编号体系

| 体系 | 一级 | 二级 | 三级 |
|------|------|------|------|
| 数字 | 1 | 1.1 | 1.1.1 |
| 第X章 | 第1章 | 1.1 | 1.1.1 |
| 混合 | 第1章 绪论 | 1.1 研究背景 | 1.1.1 国内现状 |

### 格式统一性

全文必须使用**同一种编号体系**，不可混用：
- 不应同时出现 "第1章" 和 "2" 风格的一级标题
- 不应同时出现 "1.1" 和 "1.1." 格式
- 标题编号后的分隔符统一（空格或无空格）

## 连续性检查

### 规则

1. **同级编号连续递增**：1 → 2 → 3，不应跳号
2. **子编号在父编号内连续**：2.1 → 2.2 → 2.3
3. **起始值**：正文从第1章开始

### 常见错误

| 问题 | 示例 | 处理 |
|------|------|------|
| 跳号 | 3.1 → 3.3（缺 3.2） | 插入缺失章节或重新编号 |
| 重复 | 出现两个 "3.2" | 重新编号 |
| 起始非1 | 正文从 "第2章" 开始 | 检查是否缺少第1章 |
| 子编号溢出 | "3.2.1.1.1" 层级过深 | 控制在3级以内 |
| 格式混用 | "3.1" 和 "3.1." 混用 | 统一格式 |
| 混合体系 | "第1章" 和 "2 方法" 混用 | 统一体系 |

### 特殊情况

| 情况 | 处理 |
|------|------|
| 摘要/目录无编号 | 正常，这些不参与编号连续性检查 |
| 附录用字母 | 附录A、附录B，独立编号体系 |
| 致谢/声明无编号 | 正常，不参与检查 |

## 检查范围

- 所有 SectionNode 的 chapter_path 字段
- 同一父路径下的编号递增检查
- 编号格式一致性（分隔符、前缀风格）
