# 残留内容检查

Agent 检查论文中残留的临时内容。

## 常见残留类型

### 占位符文字

| 模式 | 说明 |
|------|------|
| `TODO`、`FIXME`、`XXX` | 代码习惯带入正文 |
| `待补充`、`待完善`、`待定`、`(待填)` | 中文占位符 |
| `TBD`、`TK` | 英文占位符 |
| `...`、`……` | 作为独立段落或末尾独立出现时可能是占位 |
| `FORMULA_X_X`、`TABLE_X_X`、`FIGURE_X_X` | 公式/图表插入工具的残留占位符 |

### 空段落

- 连续两个及以上空段落 → 应删除一个
- 章节标题后的空段 → 通常多余
- 文档开头的空段 → 删除
- 文档结尾的空段 → 删除

### 试用/调试残留

- 重复的模板文本（如"请在此处输入您的摘要"）
- 标记为"示例"或"示例数据"的内容
- 临时标注的颜色/高亮

## 检查方法

1. 搜索以上关键词，列出所有匹配位置
2. 检查每处是否是真实残留（还是正常使用，如数学公式中的"...")
3. 检查首尾空段
4. 检查连续空段

## 注意

- `...` 在引文省略（"研究表明...这是有效的"）中正常，不作为残留
- 模板提示文字属于残留，不是正式内容
