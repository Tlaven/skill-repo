# 中英文摘要对照检查

Agent 检查中英文摘要和关键词对应关系的标准。

## 摘要对照原则

中英文摘要**不是翻译关系**，而是**内容对应关系**：
- 核心要素应一致：研究问题、方法、主要结果、结论
- 表达方式可以不同：中文更详细、英文更精炼（或反之）
- 长度可以有差异，但信息量应对等

## 检查要点

### 内容对应

| 要素 | 应在两个摘要中一致 | 可接受的差异 |
|------|-------------------|-------------|
| 研究问题 | 主题和范围一致 | 表述方式不同 |
| 方法名称 | 算法/模型名称对应 | 中文用中文名，英文用英文名 |
| 关键数据 | 准确率、提升比例等数字一致 | 保留有效数字的精度差异 |
| 结论 | 核心贡献一致 | 详略不同 |

### 格式一致性

| 检查项 | 标准 |
|--------|------|
| 段落数 | 通常各 1 段（部分学校允许 2 段） |
| 字数范围 | 中文 300-500 字，英文 150-300 词（按学校要求） |
| 时态 | 摘要一般用现在时或过去时，全文统一 |
| 人称 | "本文" / "This paper"，避免"我" / "I" |

## 关键词对照

### 检查要点

| 检查项 | 标准 | 常见错误 |
|--------|------|---------|
| 数量一致 | 中英文关键词数量相同 | 中文4个英文3个 |
| 术语对应 | 每个中文关键词有对应英文 | "深度学习"对应"deep learning"而非"DL" |
| 顺序对应 | 关键词排列顺序一致 | 顺序不一致 |
| 格式统一 | 分隔符统一（分号或逗号） | 中英文用不同分隔符 |
| 数量范围 | 通常 3-5 个（按学校要求） | 过多或过少 |

## 检查范围

- 提取中文摘要全文 + 中文关键词
- 提取英文摘要全文 + 英文关键词
- 并排对照，由 LLM 判断内容对应程度
