# 引用密度检查

Agent 检查正文引用分布和密度的标准。

## 基本原则

学术论文的每个技术性论断都应有文献支撑。引用密度反映论文的学术严谨程度。

## 密度标准

### 按章节

| 章节类型 | 期望密度 | 说明 |
|---------|---------|------|
| 绪论/文献综述 | 高（每段 2-5 篇） | 文献综述是密集引用区 |
| 方法/算法 | 中（每段 1-3 篇） | 方法来源、改进依据需引用 |
| 实验/结果 | 低-中（关键对比处引用） | 与 baseline 对比时需引用 |
| 结论 | 低（0-2 篇） | 可适当引用支撑主要结论 |

### 危险信号

| 信号 | 判断 | 处理 |
|------|------|------|
| 整章零引用 | 正文某章无任何 [N] 引用 | 该章缺少文献支撑，需补充 |
| 引用集中在 1-2 段 | 其他段落无引用 | 分散引用，让每段都有依据 |
| 每句都有引用 | 过度引用，像文献列表 | 适当合并，保留关键引用 |
| 只引用自己 | [N] 全部指向作者自己的论文 | 补充他人工作的引用 |

## 引用与参考文献的对应

- 正文中的每个 [N] 都应在参考文献列表中有对应条目
- 参考文献列表中的每个条目都应在正文中被引用至少一次
- 未被引用的参考文献 = 孤立条目，应删除或补充正文引用

## 检查范围

- 按章节（一级标题）统计引用标记 [N] 的出现次数
- 按章节统计正文段落数
- 计算每章引用密度（引用次数 / 正文段落数）
- 标记零引用章节
- 识别孤立参考文献条目
