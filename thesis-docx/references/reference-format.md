# 参考文献格式规范

Agent 检查和统一参考文献格式的标准。基于 GB/T 7714-2015。

## 常见文献类型标识

| 标识 | 类型 |
|------|------|
| [J] | 期刊论文 |
| [C] | 会议论文 |
| [M] | 专著/书籍 |
| [D] | 学位论文 |
| [EB/OL] | 电子资源 |
| [N] | 报纸 |
| [P] | 专利 |
| [S] | 标准 |

## 基本格式

### 期刊论文 [J]
```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```
例：`[1] 张三, 李四. 基于深度学习的目标检测综述[J]. 计算机学报, 2023, 46(3): 501-520.`

### 会议论文 [C]
```
[序号] 作者. 题名[C]. 会议名称, 会议地点, 年: 起止页码.
```

### 学位论文 [D]
```
[序号] 作者. 题名[D]. 学校所在地: 学校名称, 年.
```

### 英文文献
格式与中文相同结构。西文作者姓在前全大写、名用缩写。
例：`[1] HE K, ZHANG X, REN S, et al. Deep residual learning for image recognition[C]. CVPR, 2016: 770-778.`

## 检查要点

1. **编号连续性** — [1][2][3]... 无跳号
2. **类型标识完整** — 每条文献末尾应有 [J]/[M] 等标识
3. **标点统一** — 全中文文献用中文标点（。，），含英文的统一用英文标点（.,）
4. **作者名格式一致** — 中文作者用顿号分隔，英文作者用逗号分隔
5. **页码完整** — 期刊文章必须有起止页码

## 常见问题

| 问题 | 表现 | 处理 |
|------|------|------|
| 缺少类型标识 | "[1] 张三. 深度学习研究." | 补 [J] 或对应标识 |
| 纯 URL 当参考文献 | "https://..." | 改为 [EB/OL] 格式，加标题和日期 |
| 英文文献用中文标点 | "He K， Zhang X." | 改为英文逗号+句号 |
| 编号与引用不一致 | 正文引用 [5] 但参考文献只有 3 条 | 重新编号或补充缺失文献 |
