# 关键词一致性检查

Agent 检查中英文关键词对应关系和格式一致性的标准。

## 关键词基本要求

### 数量
- 通常 3-5 个（以学校具体要求为准）
- 中英文关键词数量**必须相同**

### 位置
- 中文关键词：紧接中文摘要之后
- 英文关键词：紧接英文摘要之后
- 格式："关键词：词1；词2；词3" / "Keywords: word1; word2; word3"

## 对照检查

### 术语对应

| 检查项 | 标准 | 常见错误 |
|--------|------|---------|
| 数量一致 | 中英文各N个 | 中文4个、英文3个 |
| 一一对应 | 每个中文词有对应英文 | 遗漏或多余 |
| 术语准确性 | 使用领域标准译法 | 自造翻译、机器翻译未校验 |
| 缩写 | 英文关键词不用缩写（除非极常见如 AI） | "DL" 应为 "deep learning" |

### 关键词与论文内容的关系

| 检查项 | 标准 |
|--------|------|
| 出现在标题 | 关键词应与论文标题的核心术语相关 |
| 出现在摘要 | 关键词应在摘要中被提及 |
| 覆盖范围 | 关键词应覆盖：领域 + 方法 + 应用（或数据集） |
| 无重复 | 关键词之间不应有包含关系（如"深度学习"和"神经网络"同时出现） |

## 格式检查

| 检查项 | 标准 | 常见错误 |
|--------|------|---------|
| 分隔符 | 中文用分号（；），英文用分号（;）或逗号（,） | 中英文混用分隔符 |
| 大小写 | 英文关键词首字母大写或全小写，全文统一 | 大小写不一致 |
| 冒号 | "关键词：" 和 "Keywords:" 格式统一 | "关键字" vs "关键词" 混用 |
| 末尾 | 最后一个关键词后无标点 | 末尾多出分号 |

## 检查范围

- 提取中文关键词列表
- 提取英文关键词列表
- 比对数量、术语对应、格式一致性
