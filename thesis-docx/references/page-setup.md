# 页面设置检查

Agent 检查论文页边距、纸张大小、页眉页脚的标准。

## 页边距

### 标准值（参考，以学校要求为准）

| 边距 | 常见标准值 | 可接受范围 |
|------|-----------|-----------|
| 上边距 | 2.54 cm (1 inch) | 2.0 - 3.0 cm |
| 下边距 | 2.54 cm (1 inch) | 2.0 - 3.0 cm |
| 左边距 | 3.17 cm (1.25 inch) | 2.5 - 3.5 cm |
| 右边距 | 3.17 cm (1.25 inch) | 2.0 - 3.0 cm |
| 页眉距离 | 1.5 cm | 1.0 - 2.0 cm |
| 页脚距离 | 1.75 cm | 1.5 - 2.5 cm |

### 检查要点

| 检查项 | 标准 | 常见错误 |
|--------|------|---------|
| 左右对称性 | 左边距通常 ≥ 右边距（装订线） | 左右边距完全相同（无装订空间） |
| 分节一致性 | 正文各节边距应一致 | 不同章节边距不同 |
| 特殊页面 | 封面/声明页可不同 | 正文页用了封面边距 |

## 纸张大小

| 检查项 | 标准 |
|--------|------|
| 纸张尺寸 | A4 (21.0 cm × 29.7 cm) |
| 方向 | 正文纵向（portrait） |
| 特殊页面 | 附图/宽表可用横向（landscape） |

## 页眉页脚

### 页眉

| 检查项 | 标准 |
|--------|------|
| 内容 | 通常为论文标题或章节名 |
| 分节 | 不同章节可有不同页眉 |
| 字体 | 五号宋体，居中 |
| 分隔线 | 页眉下方通常有横线 |

### 页脚（页码）

| 检查项 | 标准 |
|--------|------|
| 前言部分 | 罗马数字（i, ii, iii...） |
| 正文部分 | 阿拉伯数字从 1 开始 |
| 位置 | 页面底部居中 |

## 检查范围

- 文档所有 section 的页边距
- 纸张大小和方向
- 页眉页脚文本内容
