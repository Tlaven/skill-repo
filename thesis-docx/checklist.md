# 论文质量检查清单

## 使用方式

1. 按类别逐项检查，每项打 ✓ / ✗ / N/A
2. 能用 CLI 命令自动化部分用 `python cli.py ...` 注明
3. 部分检查依赖人工判断，无法完全自动化

**优先级标注：**
- 🔴 **必检** — 不过别交稿（残留内容、缺标题、编号混乱）
- 🟡 **应检** — 影响审稿观感（表格格式、字体不一致、引用错误）
- 🟢 **选检** — 锦上添花（写作风格、附录规范、单位格式）

---

## 1. 表格

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 1.1 | 每个表格都有 Caption（"表X.Y 标题"） | `read-tables` 输出中 caption 为空即为缺 | 例外：排版用的无边框表 |
| 1.2 | 内容不是占位符（无 `A/B/3/4/a/b/c/d` 等） | 人工 | 常见于模板残留 |
| 1.3 | 内容与所在章节主题相关 | 人工 | 如代码生成论文中出现 U-Net 表则异常 |
| 1.4 | 表号与图号不混用（标题不叫"图X.Y"） | 人工扫 `read-tables` 输出 | 误标为图的表 |
| 1.5 | 数据行数 ≥2（1 行数据不值得用表） | 人工 | 单行应改为文字描述 |
| 1.6 | 正文中有引用（"如表X.Y所示"） | 人工 + `search --regex "表\\d+-\\d+"` | 有表无引用 vs 有引用无表均异常 |
| 1.7 | 表格格式为三线表（顶线/表头线/底线，无竖线） | 人工 | 中文学位论文标准格式；常见违规：数据行间有横线、有竖线 |

## 2. 图片

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 2.1 | 每张图都有 Caption（"图X.Y 标题"） | `read-images` 输出中 caption 为空即为缺 | |
| 2.2 | 图片清晰可读（不模糊、不拉伸） | 人工 | 位图至少 300dpi |
| 2.3 | 正文有引用（"如图X.Y所示"） | `search --regex "图\\d+-\\d+"` | |
| 2.4 | 图号不跨章重复 | `read-images` + 人工 | 如两章都有"图3-1" |

## 3. 公式

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 3.1 | 所有 `FORMULA_X_X` 占位符已清除 | `search --query "FORMULA_"` | insert-formula 不自动清理 |
| 3.2 | 公式编号连续、不重复 | `read-formulas` + 人工 | |
| 3.3 | 正文有引用（"如式(X.Y)所示"） | `search --regex "式\\(\\d+\\.\\d+\\)"` | |

## 4. 编号体系

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 4.1 | 章节编号连续（1, 2, 3… 无跳号） | `read-structure` + 人工 | 如直接从 1→3 跳 2 则异常 |
| 4.2 | 图/表/公式编号格式统一 | 人工 | 全表用 `X-Y` 还是 `X.Y` 需一致 |
| 4.3 | 正文引用编号与实际目标匹配 | 人工 | 如正文说"表7-1"但实际只有表6-1 |

## 5. 文档结构完整性

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 5.1 | 目录已生成且页码与正文一致 | 人工 | 目录应是 Word 自动目录（域代码），非手打 |
| 5.2 | 页码体系正确（前言罗马数字、正文阿拉伯数字从1开始） | 人工 | 常见错误：正文不从1开始、前言与正文页码连续 |
| 5.3 | 中英文摘要内容对应、关键词翻译一致 | 人工 | 关键词顺序和翻译应严格对应 |
| 5.4 | 致谢存在 | 人工 | |
| 5.5 | 原创性声明存在 | 人工 | |

## 6. 代码

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 6.1 | 代码使用等宽字体（Consolas / Courier New 等），与正文区分 | `search-format` + 人工 | 常见错误：代码用了宋体或 TNR |
| 6.2 | 代码保持原始缩进，未在 Word 中被重新排版 | 人工 | Word 自动换行可能打乱缩进 |
| 6.3 | 代码有专门样式（如"代码"样式），非手动逐行改格式 | 人工 | 保证全文代码外观一致 |
| 6.4 | 过长代码（≥20行）建议移入附录 | 人工 | 正文应只展示核心片段 |
| 6.5 | 代码块有编号标题（"代码X.Y"）或至少标注了语言 | 人工 | 多段代码时应有编号便于引用 |
| 6.6 | 代码前后有正文解释其功能/逻辑，非裸放 | 人工 | 代码不能替代文字论述，与图/表同理 |
| 6.7 | 正文中有对代码的引用（"如代码X.Y所示"） | 人工 + `search --regex "代码\\d+"` | 有代码无引用属写作不完整 |

## 7. 残留内容

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 7.1 | 无占位符文字（TODO、xxx、待补充） | `search --regex "TODO|待补充|xxx|待定"` | |
| 7.2 | 无 `FORMULA_X_X` 残留 | `search --query "FORMULA_"` | 同 3.1 |
| 7.3 | 无 `TABLE_X_X` / `FIGURE_X_X` 残留 | `search --regex "TABLE_\\d|FIGURE_\\d"` | 占位符混入正文 |
| 7.4 | 无空段落或仅含空格段 | `search-by-style` + 人工 | |

## 8. 样式与格式

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 8.1 | 标题样式链完整（Heading 1 → 2 → 3 不跳级） | `read-structure --verify` | Heading 1 后直接 Heading 3 属异常 |
| 8.2 | 正文段落统一使用 Body Text 样式，而非 Normal + 手动改格式 | `search-format` + 人工 | 用样式而非直接格式，便于一键修改 |
| 8.3 | 无冗余自定义样式 | `extract-rules` + 人工 | 如 `NormalNoSpacing`, `a`, `a1` 等模板残留样式应清理 |

## 9. 图/表标题

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 9.1 | 图标题和表标题均用 Caption 样式，全文统一 | `read-tables` + `read-images` + 人工 | 不应有的用 Caption、有的手动加粗、有的用其他样式 |
| 9.2 | 表标题在表上方，图标题在图下方 | `read-table-context` + 人工 | 中文论文惯例；位置放反属常见错误 |
| 9.3 | 标题末尾无句号 | `search --regex "^(表|图)\d"` 结果中人工看结尾 | 中文论文惯例：图/表标题末尾不加标点 |
| 9.4 | 编号格式全文统一（X.Y 或 X-Y 二选一，不混用） | 人工 | 混用"表3-1"和"图2.1"在同一篇论文中不规范 |

## 10. 字体与排版

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 10.1 | 中文用宋体、英文/数字用 Times New Roman | 人工或 `search-format` | 常见问题：中文用了 Times New Roman 或英文用了宋体 |
| 10.2 | 标题层级不超过四级 | `read-structure` + 人工 | 中文学位论文通常到 1.1.1.1 为止 |
| 10.3 | 中文与英文/数字之间的空格一致 | 人工 | 中文与英文之间通常加空格，需全文统一 |

## 11. 参考文献

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 11.1 | 无未引用的参考文献 | `list-references --verify` | |
| 11.2 | 无未定义的引用标记 | `list-references --verify` | |
| 11.3 | 引用编号按出现顺序排列 | `list-references --verify` | |
| 11.4 | 参考文献格式统一（作者/标题/期刊/年份完整） | 人工 | |

## 12. 页面与版式

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 12.1 | 页面尺寸 A4、边距符合学校要求 | `read-page-setup --verify` | |
| 12.2 | 页眉/页脚内容正确 | 人工 | 如页眉是否有"第X章" |
| 12.3 | 行距、首行缩进全文一致 | `read-section --verify` | |

## 13. 交叉引用

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 13.1 | 图/表/公式引用是 Word 域代码（可自动更新），非手打数字 | 人工 | 手打编号在增删图/表后会错位 |
| 13.2 | 正文引用的图/表/公式确实存在 | 人工 | 引用编号指向的对象存在且正确 |

## 14. 附录

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 14.1 | 附录标题格式正确（"附录A"而非"第6章"） | 人工 | 附录编号用 A/B/C，不与正文章节混排 |
| 14.2 | 附录中的图/表/公式编号含附录标识（如图A-1） | 人工 | 附录中的编号不应与正文冲突 |
| 14.3 | 正文有对附录的引用（"详见附录A"） | `search --regex "附录[A-Z]"` | 无正文引用的附录可删除 |

## 15. 数字与单位

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 15.1 | 数字与单位之间空格一致（"10 cm" vs "10cm"） | 人工 | GB 建议数字与单位间留空 |
| 15.2 | 单位大小写统一（"km" 非 "Km", "kg" 非 "KG"） | 人工 | 常见错误：单位大小写不敏感导致不统一 |

## 16. 写作风格（建议性）

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 16.1 | 无套路化开头（"随着…的发展"） | `search --writing-style` | |
| 16.2 | 无连接词堆砌（"然而"、"因此"连续使用） | `search --writing-style` | |
| 16.3 | 无机械列举（"首先…其次…再次…最后…"） | `search --writing-style` | |
| 16.4 | 摘要不超过规定字数 | 人工核对 | |

## 17. 术语规范

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 17.1 | 英文缩写首次出现时附全称 | `search --regex "\b[A-Z]{2,}\b"` 列出所有大写缩写，人工核对其首次出现处是否有全称 | 中文论文惯例：大语言模型（Large Language Model, LLM），后续直接用 LLM |
| 17.2 | 缩写全文写法统一 | 人工 | 同一个缩写不应在不同章节写成不同形式 |

## 18. 标点符号

| # | 检查项 | 自动化 | 说明 |
|---|--------|--------|------|
| 18.1 | 中文句末用中文标点（。而非.） | `search --regex "[a-zA-Z]\. \"`（辅助找出 English.后面接中文的部分） | 常见错误：中文段落结尾用英文句号 |
| 18.2 | 引号/括号前后文统一 | 人工 | 中文前后引号不成对、中英文括号混用 |

## 速查：常用检查命令

```bash
# 表格概览 + 缺 Caption
python cli.py read-tables "论文.docx"

# 图片概览
python cli.py read-images "论文.docx"

# 公式列表 + 编号
python cli.py read-formulas "论文.docx"

# 残留占位符
python cli.py search --regex "FORMULA_|TABLE_|FIGURE_|TODO|待补充|xxx" "论文.docx"

# 引用一致性
python cli.py list-references --verify "论文.docx"

# 样式异常（文本像标题但未标）
python cli.py read-structure --verify "论文.docx"

# 写作风格问题
python cli.py search --writing-style "论文.docx"

# 页面设置
python cli.py read-page-setup --verify "论文.docx"

# 列出所有大写缩写（辅助核首次全称）
python cli.py search --regex "\b[A-Z]{2,}\b" "论文.docx"

# 全文章节结构
python cli.py read-structure "论文.docx"
```
