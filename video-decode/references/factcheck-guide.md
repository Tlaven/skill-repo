# Factcheck Guide — 视频说法逐项核查方法

## 1. 抽 claims (四类)

从解读稿中抽出**可核查项**, 不遗漏关键数字:

| 类型 | 例子 | 核查要点 |
|---|---|---|
| 政策参数 | "首套、≤120㎡、≤150万, 中央出90%" | 找原始文件逐条比对 |
| 数字 | "存款余额347万亿" "净利润2.4万亿" | 找官方统计/权威报道, 注意口径与时间点 |
| 出处归属 | "某某会议9月提出的六张网" | 核对"谁、在哪、什么时候"提出 |
| 直接引用 | "官方称这是首次" | 找原话出处 |

观点/推演/预测类**不进核查表** (或标注"观点, 无法验证"), 不要给观点打分 (观点分析见 §7 结构分层: 裸观点只标性质, 推理型才评级)。

**多人谈话型**: claims 分散在闲聊/跑题中 — 按主题聚类抽取, 区分亲历/转述/玩笑与可核查事实; 官方人工字幕也会有专名错字 (实测: "王晓光"被字幕写成"王小光"), 核查以官方通报/原始文件为准, 报告中标注"字幕作 X, 实为 Y"。

**术语纠正三条件** (对 "疑为 X" 升级前必过): ① 候选词在 T1/T2 来源真实存在 ② 原词在语境中不成立 (不成词/与史实矛盾) ③ 替换后语义自洽 — 同时满足才在报告写 "实为 X (附来源)", 否则标 "疑为 X" 或 "无法判断"。检索无果 ≠ 原词错误 (弱证据, 不可反推); **宁可漏纠不可错纠** (漏纠会被官方原文自然纠正, 错纠是无痕注入新错误)。原稿永不改写, 纠错只出现在解读/核查层。

## 2. 信源分级 (T4 不能当证据)

| 级 | 来源 | 用法 |
|---|---|---|
| T1 官方 | gov.cn / 部委网站 (mof.gov.cn, pbc.gov.cn, stats.gov.cn) / 美联储 federalreserve.gov / 交易所公告 | 最高证据, 引用时给链接 |
| T2 权威媒体 | 新华社/新华财经/Reuters/CNBC/财联社/第一财经 | 可作证据; 优先引用其中转述的官方原文 |
| T3 机构研报/专家 | 中金/粤开/兴业/东方金诚等 | 解释性证据, 需与 T1/T2 交叉 |
| T4 自媒体/视频本身 | 各类公众号、视频、社媒 | **仅作 claim 来源, 绝不作核查证据** |

## 3. 检索方法

- 一次查一个 claim 组; query 加 "官方/通知/公告/统计局/央行/财政部" 等词提升命中
- 政策类优先找**原始文件名+文号** (如 财金〔2026〕95号)
- 数字类找**最新月度/季度官方数据**, 注明时间点 (如 "8月末")
- 每个关键结论至少 **2 个独立来源** 交叉; 单一来源时注明"单一来源"
- 搜不到: 换措辞 → 加来源词 → webfetch 兜底页; 仍无 → 标"无法验证(未检索到可靠来源)", 如实说明检索范围

## 4. 四类结论定义

| 结论 | 判定标准 | 输出要求 |
|---|---|---|
| ✅ 属实 | 与 T1/T2 来源一致 | 附来源链接 |
| ⚠️ 有出入 | 方向对, 但数字/细节有偏差 | **给出官方值**, 说明偏差幅度 |
| ❌ 错误 | 与 T1/T2 矛盾 (数字明显错/出处归属错) | 给出正确事实 + 来源 |
| ⚖️ 无法验证 | 观点/推演/预测; 或查无可靠来源 | 注明属于"观点"还是"检索无果" |

**口径差异不算错误**: 同一概念多口径时 (例: 广义赤字率 8.1% 与 9.4% 是两种口径) 标注 "口径差异, 非错误"。

## 5. 输出模板

```markdown
## ✅ 核实属实
| 视频说法 | 实际情况 | 来源 |
|---|---|---|

## ❌ 发现的问题
| 视频说法 | 问题 | 官方/实际值 | 来源 |
|---|---|---|---|

## ⚖️ 无法验证 (观点/推演)
- ...

## 总评
- 核心事实准确度: ...
- 错误是否影响主逻辑: ...
- 事实核查与观点评价的边界声明
```

## 6. 反模式

- 拿自媒体/T4 当核查证据 (循环论证)
- 对观点类内容强行"核实真伪"
- 只看一篇文章就下结论; 忽略发布时间 (旧数据当现状)
- 把口径差异、四舍五入误差报成"错误"
- 编造来源或"检索无果"时含糊其辞
- **同机构多期数字被拼接当"范围扩大"** (2026-10 实测: 视频称"贩运年收益1500亿, 算上奴役剥削飙至2360亿", 实为 ILO 2014 与 2024 两期报告中**同一个口径**"强迫劳动年利润"的新旧估计 → 逐个数字查原始报告的年份与定义, 不接受视频给定的分类框架)
- **估计值被绝对化** (2026-10 实测: IOM "近80%跨国贩运**经由官方口岸**过境, 其中23%无本人证件、9%用伪证" 被转述成 "80%受害者**持本人证件合法出境**" → 核对原始表述的限定语: 近/至少/其中/约)
- **术语纠错无锚点/静默改写原稿** (纠错没锚点=猜; 改错原稿=无痕注入新错误; 检索无果不能反推原词错 — 见 §1 三条件)

## 7. 观点分析 (合理性 + 可验证性) — 用户要求"分析作者观点"时

事实核查只回答"对不对"; 观点分析回答"论证是否站得住"。流程:

1. **拆解论证**: 每个核心论点拆成 前提 → 推理 → 结论; 写出隐含假设
2. **观点结构分层 (先分类, 再评级)**:
   - **A 裸观点** (无推理链) — **不打"合理/不合理", 只标性质**:
     - A1 价值/规范判断 ("应该…") → 查是否明示价值前提、是否自洽/双标 → 标 **"立场"**
     - A2 预测 ("大概率…") → 查可证伪性、基准率、有无机制 → 标 **"预测(待证)"**
     - A3 修辞/隐喻 → 查它暗示的因果、偷换的概念 → 标 **"修辞"**
   - **B 推理型观点** (前提→推理→结论) — **唯一做合理性评级的类别**, 且分维度:
     - 前提核查 (每个前提先归类: 硬事实/统计/规范)
     - 推理有效性 (机制存在? 相关≠因果? 前提成立时结论撑得住?)
     - 抗反例 / 遗漏变量
     - 结论溢出 (量级夸大)
   - **C 混合型** (前提里夹带更基本的观点/私设公理) — 先分离**事实前提**与**价值前提**, 分别按 A/B 处理; 警惕价值前提伪装成事实前提 (例: "人性自私→婚姻是契约", "人性自私"是私设前提, 不是可核查前提)
   - 纪律: A 类不打分 (避免"我不认同其价值→判它不合理"的偷换); B 类不因结论符不符合自己立场调分; **"合理性" ≠ "我同意"**
3. **可验证性分类** (作用于 B 的前提与 A 的亚类):
   - 硬事实类 → 走 §1-5 核查流程
   - 统计趋势类 (好感度变化/质量变化) → 找系统性数据; 找不到如实标"无系统证据"
   - 规范/结构判断类 (应不应该/结构性矛盾) → 不可验证, 只评估论证质量
4. **论证质量五项检查** (作用于 B/C):
   - **案例选择性**: 是否只列支持结论的案例? **主动在作者自己的案例里找反例** (实测: 作者举的案例常常自带反例)。含**数据终点选择性**: 引用数据是否截断在支持结论的时点 (实测: 用 2024 结婚数论证趋势, 却略过 2025 回升)
   - **因果跳跃**: 相关≠因果; 警惕"把市场驱动的成功归因于政策推动"类错误归因。含**遗漏变量**: 是否遗漏文献公认的主导因素 (实测: 彩礼话题略过性别比失衡、结婚数话题略过民俗年份因素)。含**因果方向/时序检查**: 对"制度修订→现象出现"类解释, 对照官方表述与时间线 (实测: 视频称"2023条例修订→通报增多", 但2018已有案例、官方称修订系"针对执纪监督中发现的问题"—因果可能倒置, 实践在先)
   - **量级夸大**: 个案 → 整体趋势的概括是否成立; 区分"约束存在"与"空间为零/到头了"
   - **共识对照**: 对"到头了/没空间/倒计时"类判断, 检索同期专家论坛、研报、官员表态 — 标注作者是主流还是少数派
   - **立场识别**: 查作者背景/发布平台 (1 次搜索), 标注视角, 不做人身攻击
5. **文献对照**: 结构性观点用学术研究/专家分析裁判 (如 Cool Japan 失败分析、软实力实证研究)
6. **错误方向检查**: 事实错误未必削弱论证 — 判断错误方向是强化还是削弱作者结论 (例: 某视频把 PSL 余额高估 3 倍, 但其结论是"PSL 影响有限", 错误反而强化结论)
7. **输出结构**: 观点结构表 (论点 | 结构类型 A/B/C | 前提与论据 | 核查结果 | 评级) — **评级仅出现在 B/C 行且按维度** (前提可信度 / 推理强度 / 抗反例), 不给笼统总分; A 行只标 "立场/预测/修辞"。附 "哪些站得住/站不住" + 总评 (总评声明事实核查与观点评价的边界)
