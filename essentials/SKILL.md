# Essentials — 经验的入籍审核

> **主型:元型**(决定验收:交接复现);**副型:判断型**(正文是判定规则)。类型定义见 `seeding-skills` 的 `references/skill-types.md`。
> **状态:** v0.3(重定位,活跃)· **未转正**。v0.1–v0.2 走"文档工厂"定位,六轮评测无净增益(`tests/evidence/`);本版把产物从文档改为账本,**交接复现尚未跑**。

## 定位

一句话:把实践里冒出来的判断,按证据**升格**成可加载的上下文;证伪即退役。三层里只有它朝外取证:

- `init-project-docs` — 已知该记什么(供给 / 加载)。失败 = 忘掉、漂移。
- `seeding-skills` — skill 本身怎么长。失败 = 僵化、膨胀。
- **essentials** — 还不知道的:从哪取得、凭什么算数、何时有资格进供给。失败 = 错误经验被固化、复用。

**边界:** 不写代码、不产调研报告、**不替用户拍板**(价值与边界只记录用户的裁决,不代拟结论)、不做没有证伪条件的累积。已有可靠脚手架直接用;已否决方案走 ADR。

## 环路(四步,不能省)

- ① **摩擦** → 收可观测的失败信号,记进"事件"列。
- ② **候选** → 一句话断言 + **证伪条件**(什么现象会推翻它);不写证伪条件不入账。
- ③ **检验** → 按「判据来源」取证,留下证据指针。
- ④ **晋升 / 退役** → 生效或退役,证据一行,视图重誊。

**挂点:收尾。** 每次收尾过一遍——本次有没有被否决 / 返工的判断?有 → 一行候选;没有 → 不写;顺手跑账本的引用 grep 更新排序。【依据:每次收尾 + 四份样例 0 条引用 = 无挂点的环路空转】

## 触发(事件型,不许内省)

- 用户的否决 / 返工 / "这个我说过" / 同一决策被重复解释【实测:B 矩阵指出"只有写入、没有读取"】
- 检查器、QA、测试失败,且原因不是笔误
- 用户点名,或问"你可靠吗 / 这是你擅长的领域吗" → **只出可靠度声明**(声明本身不入账;由它引出的检验结果才入账)

**可靠度声明**(一句话三档):① 只有一种公认写法 ② 多个语义相近实现 ③ 没有先验。②③ 才进环路。

## 账本(唯一真相)

- 居所:`docs/scaffolds/<domain>-ledger.md`;模板 `templates/ledger.md`;第一份落盘才建目录。
- 一行 = 事件 / 断言 / 层(`[通用]` `[本地]`) / 证伪条件 / **证伪动作** / 判据+取证 / 状态 / 载体。断言前写 `[约定]` 的走用户裁决,其余按事实类取证。
- **证伪动作是执行方式,四选一**:`复跑:<命令>` / `对照:A vs B` / `盲评:<prompt>` / `人看:<一句话问题>`。**没有动作不入账**(可标"待设计动作",不进视图)。
- `*-essentials.md` 是账本誊出的**视图(缓存)**,不是真相;冲突以账本为准。
- **冷启动例外**:账本全是候选时,视图照常誊并标「候选」;出现生效条目后,候选退出视图。
- 加载:项目 L1 一行"脚手架 → `docs/scaffolds/`" + 加载表"进弱领域 → + 相关视图"(加载表写法按 `init-project-docs` 的 L1 模板)。**只写不读等于没搭。**

## 检验源与晋升

**强度取决于判据来源,不取决于谁跑。** AI 可自跑复跑 / 对照 / 盲评;但必须 提案者 ≠ 判定者 ≠ 执行者(至少换会话),判据**开跑前**预注册留档,盲评隐组别。

| 判据来源 | 取证方式 | 能晋升什么 |
|---|---|---|
| **用户编码**(判据落成测试 / 检查器,可回指用户的引入记录) | 复跑、回归 | 事实:数值、配比、流程项(**满强度**) |
| **用户确认过的判据**(用户听过并认可一句可判的话) | 复跑、A/B 对照、盲评 | 事实 + "更好"类声称 |
| **AI 自拟的判据** | 同上 | **只到候选**,用户确认判据后升 |
| **用户裁决**(含可观察边界的取舍句) | 复述确认一次,记 `用户裁决@日期` | 约定:红线、取舍、边界;事实类只能记「观察级」(仅作线索) |

- **AI 可以自己跑检验**:起草证伪条件、搭夹具、复跑、派盲评——这是默认动作,不是例外。
- AI 自建的检查器**不算用户编码**——除非有用户的引入记录(提交 / ADR);否则按"AI 自拟判据"处理。
- **用户的感觉**(未复述确认)不计证据,只记一条摩擦事件;同一感觉重复一致后再请确认。
- **否决也分级**:用户 / 用户编码的证据可判退役,AI 自拟判据的否决只降回候选。事实类不得拿用户裁决当满强度证据,只能记「观察级」——仅作线索,不进视图,不得当作别的断言的证据;约定类不得用复跑晋升。
- **不可自测是一等公民**:视觉观感、审美、体感没有可跑的判据,`人看` 就是合法终态,不是欠债——但必须写**看它的时机**(哪个里程碑)。代理指标(如抽色 / 量间距)可以记,不得用它晋升审美断言。

**晋升三条件(全中):** ① 能回指一次真实事件;② 写清推翻它的现象;③ 判据来源与断言类型匹配。
**退役(分层):** 事实类——自生效日起累计引用 0 且满 90 天【假设待测】→ 回候选,再满 90 天仍 0 → 退役;候选——入账满 90 天 0 引用(用户未接手)→ 退役;约定类**不因 0 引用退役**(防事故的规则,没出事才是它的产出),只由用户复评退役(触发 = 用户否决 / 返工);被证伪者按「否决也分级」处置。

## 载体分诊(三类不落一处)

- 反先验事实 → 贴着它约束的代码 / ADR(读代码时才会用上)。
- 本地标定 → 账本 → 视图(需要跨会话加载)。
- **强制程序 → 检查器 / hook / 提交前清单**(散文拦不住动作)。【实测:盲评里带 skill 组把"标准"当材料,反成负担】

于是账本留全量,视图只装"能跨会话加载"的那一类:强制程序只留编号 + 检查器指针,正文不进文档。视图 = 红线 + ≤5 条,生成规则见 `templates/ledger.md` 的「二、视图」。【实测:四份样例 0 条使用记录】

## 红线

- ❌ 条目无证伪条件 / 候选当结论
- ❌ 强制程序写成散文
- ❌ `[本地]` 条目复制到别的项目
- ❌ "用了 N 次没出事"当证据
- ❌ 内省式理由("我觉得这领域弱")当触发

## 验收(teach-back)

- **档位:** teach-back;口径为**交接复现**,不再用"方案质量"。
- **流程:** 开跑前预注册(本域最该被砍的 3 条判断 + 通过线)→ 派独立 agent,只给 视图 + 项目 L1 + 一个弱领域任务 → 比对它砍掉 / 改掉的提案;协议见 `references/handoff-replication.md`。
- **指标:** 复现率 / 重复解释次数 / 误引率(把方法当材料的次数);**未跑即标「未转正」**;留档 `docs/reviews/YYYY-MM-DD-<域>-essentials.md`。
- **演化信号(任一):** 账本长期 0 行 / 候选积压未晋升 / 晋升缺证据 / 视图被绕过 / 强制程序又写回文档;版本归 git,负结果在 `tests/evidence/`。
