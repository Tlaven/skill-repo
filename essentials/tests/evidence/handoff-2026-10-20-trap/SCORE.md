# 陷阱版重跑 · 判分（2026-10-20）

> A 无材料 / B 真实视图（含 V8）。提示词**不含**"密度已被认可"。
> n=1，agent 初评，待用户确认。

## 一、结果

| 判定 | A 基线 | B 视图 |
|---|---|---|
| J1 定位在图形设计层 | **0**（"叙事层"） | **1**（"图形设计层：视觉语言 / 节奏 / 层级"） |
| J4（反向）提出加模块 / 加密度 / 加内容 / 加页 | 未犯 | 未犯（明说"不加模块、不追加数据"） |

**动作对比**

- A：定 deck 级结论、标题改断言、**11 页压到 7 页、模块砍到 1–2 个**、做一页重点页、补 so-what。
- B：视觉母题、强调色只给锚点、2–4 级层级表、两级间距刻度、刻意不对称布局；明确不动内容与密度。

## 二、判读

1. **J1 出现 0 vs 1 的差距**——这是三轮以来第一次，基线组完全没到目标层。
2. **但 J4 没有区分度**：A 没有"加模块"，而是走向**反面**——砍页、砍模块。这不是预注册的陷阱，是另一个已知失败（v0.1 稀疏 → 用户判"不够丰富"）。
   → 按预注册规则，本轮对 J4 判"无区分度"；A 的"过度削减"只能算**事后观察**，不能算结果。
3. B 的表现是**检索**不是**迁移**：视图里就有"图形设计层、不是加模块"，B 几乎逐条复述。对"加载视图后是否复现用户判断"这个问题，这正是要的证据；对"视图能否泛化到新问题"，不构成证据。
4. A 的方案本身并非荒谬（叙事确实是问题）；它与 gold 的分歧说明：**gold 是单点裁决，不是全序**。视图的作用是让 agent 站在用户那一侧，而不是找到"唯一正确"。

## 三、结论

- **机制成立**：加载视图的会话复现了用户裁决，未加载的没有。这是 handoff 主张第一次得到正向信号（n=1）。
- **不足以转正**：单次、单任务、答案部分在视图里、判分者是 agent。
- **下一轮若要更严**：加 J5（反向的另一半：是否提出削密度 / 砍页），并把每组重复 3 次看稳定性。但边际收益在下降。

## 四、建议

停止合成测试，转入真实使用：

1. 下一次真实 pptx 任务加载视图；
2. 决策笔记写 `vq#V<n>`；
3. 收尾时跑一次引用 grep；
4. 累计 ≥3 次真实引用后，用真实决策做交接复现（gold = 当时的用户裁决），再谈转正。
