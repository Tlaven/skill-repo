# 交接复现 · 判分（2026-10-20，pilot）

> 三组各一个独立会话，同一提示词，唯一变量是加载材料（见 `PREREG.md`）。
> 判分：agent 初评，**待用户确认**；先读输出、后看组别。

## 一、逐条判定

| 判定 | A 基线 | B 全文 | C 视图 |
|---|---|---|---|
| J1 问题在图形设计层 | 0.5（主判“观点层”，但点出版式趋同 / 视觉母题 / 无锚点） | 0（主判“结构层”，只顺带提卡片阵列） | 0.5（主判“叙事与识别层”，点出色彩角色被摊平、无记忆点） |
| J2 动作是改视觉语言 | 1（签名页 / 视觉母题 / 强调色） | 1（原型轮换 / 每页焦点 / 底部锚线） | 1（色彩角色 / 全幅单图 / 每页锚） |
| J3 未复述素材的密度规则 | 1 | 1（明说“不靠增加模块”） | **0**（写“模块数仍 ≥3”——照抄素材规则） |
| **合计** | **2.5** | **2.0** | **2.0** |

## 二、判读

1. **无一组明确到达 gold**（“图形设计层：构图语言 / 图形与图标系统 / 色彩层次”）。三组都停在“叙事 / 结构 / 观点”这一带，把视觉问题当附属。
2. **B ≈ C < A**：带材料的两组没有超过基线；视图组还把素材里的“模块 ≥3”当解法复述了一次（J3 失分）——正是“素材锚定”的形态。
3. **更可能的解释是覆盖缺口，不是传递失败**：gold 那条判断原先只存在于 `slide-patterns-essentials.md` 的 v0.2 版本行里，从未被提升成一条可执行条目；夹具里删掉那一行后，材料里就**根本没有这条判断**。任何组都只能靠自己想到。
   → 这正是“记录 ≠ 晋升”：版本表里写了，但没变成规则/条目。
4. 附带证据：B 组的表现说明旧文档能把“已有条目”用起来（原型轮换 / 焦点 / so-what 都对上了），缺的是**没被写进去的那条**。

## 三、结论（pilot 级）

- **不转正**。这一轮既不能证明视图有传递力，也不能证伪；它暴露的是一个更基础的缺口：**最重要的判断没入账**。
- 下一步（顺序）：
  1. 把 v0.2 终评提升为一条 `[通用]` 约定类条目：断言“密度达标后，观感差距在图形设计层（构图语言 / 图形与图标系统 / 色彩层次）”，证伪条件“按此方向改一轮后用户仍判普通”，证伪动作“人看：下一轮终评”；
  2. 重跑同一夹具（这次 gold 在账本里，但仍**不进视图**，测视图是否够）；
  3. 若仍不到，判“视图容量不足 → 拆域”，而不是继续加规则。

## 四、局限（必须写）

- n=1，每组只有一次；同模型家族；判分者是 agent 不是用户；gold 是我对用户终评的转写，可能偏窄；
- 任务描述里“密度已被认可”可能已经替三组排除了“加密度”这条错路，抬高了 A 组；
- 夹具是从真实文档复制并删行得到的，不等于原文档在真实使用中的表现。
