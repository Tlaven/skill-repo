# 用 essentials 审计 essentials(v0.2)

## ① 分诊结论

**不造。** 三类问题（即分诊三问）虽然全部通过——但"已有脚手架 → 只做生长"是更靠前的判断条件：这个领域已有一份脚手架，就是这份 SKILL.md；再"造"一次等于把它改成 v0.3。若在 `docs/scaffolds/` 里另落一份"如何造脚手架"，就正好违反它自己"不设跨项目单源"的禁令。

三问逐一核对：

- **① 有唯一公认写法吗?没有。** 邻近实践很多（checklist / ADR / runbook / eval / AGENTS.md），但没有任何共识文本规定"不可检索的判断该怎么沉淀"。**过。**
- **② 会重复出现吗?是——但重复发生在 skill 层，不在项目层。** 单个项目通常只把判定方案定一次（接近"只此一次"）；反复发生的是"每进入一个新弱域就要重跑这套流程"。② 确实通过，并恰好把产物从项目文档推到 skill 本体。
- **③ 赌注大吗?大，但按它自己的判断标准。** 不是损失量级大，是"错了会静默扩散"：一份坏的 essentials 会被每次会话加载、静默扭曲推荐，而且看起来权威。**过。**

因此，三问通过；但"不该用"第 1 条（已有完善脚手架的领域：直接用，只做生长）优先。"完善"不是门槛，"已有"才是——生长机制正是给不完善脚手架准备的。**下面的删、留清单就是这份 v0.3 的修改差异。**

## ③ 可证伪预测（每条含观察信号与证伪条件）

**P1 — 删「红线」独立区（迁入决策卡模板）**
会变差的是：**决策前的禁令扫描消失**。红线在 SKILL.md 里唯一的作用是"每次都出现在上下文中"；一旦只剩模板槽位，冷启动时最容易被跳过——而"候选当结论""无来源条目"正是那种事后才被发现、只能靠一次性扫描挡住的错误。
观察信号：接下来 20 次进入弱领域决策的会话中，(a) 实际被读取的决策卡里含 ≥3 条红线的比例；(b) 决策记录里「候选」被当成结论（或未经否决就落地）的条数。
证伪：若 (a) = 100% 且 (b) 相对删前不上升 → P1 错，红线区纯冗余。

**P2 — 删或降级数字阈值（"两周"、观察项 ≤5、"无引用取前 5"）**
会变差的是：**唯一的垃圾回收机制停摆**。文档默认只增不减；观察项会因为"压不成强制步骤就标观察项"而无上限膨胀，成为非执行规则的收容所。
观察信号：处置后 30 天统计 (a) 0 引用却仍处"活跃"的条目占比；(b) 单份文档观察项 >5 条的文档占比；(c) 文档净增行数。
证伪：若 30 天后 (a) ≤20% 且 (b) ≤10% 且净增 ≈0 → 淘汰与自限来自别处，数字确属未标层的多余拍板。

**P3 — 删范围句（"不写代码""纯执行任务""不产调研报告"合为一句或删净）**
会变差的是：**边界从"判断脚手架"漂向"领域综述"**——出现无触发事件的定义、术语、最佳实践章节，条目从"某坑 → 规则"变成"关于该领域"。
观察信号：新增或大改的 essentials 文档中，(a) 无触发事件的条目占比；(b) 文档行数中位数；(c) 出现"背景 / 术语 / 最佳实践"类标题的文档比例。
证伪：若 (a) 维持 ≤10%、(b) 不升、(c) 为 0 → 这些句子只是礼貌，删了无害。

> 附带一个同样可证伪的判断：**其余降级（状态三态、"先例优先"、`seeding-skills` 依赖、变更史一句）我预测删了不会变差。** 若 3 个月内出现"域复活后误用过期标定"或"先例挖掘质量下滑"的具体案例，则此判断错。

## ④ 这份 skill 最该保留的三样东西

1. **事件锚定**——"每条回指一次真实触发事件，写不出不收"（+ 版本表一行 = 触发事件 + 变更）。
   这是唯一的**写入口闸门**。没有它，"只收三类"只是口号，文档会在两次迭代内退化成领域综述。它不可先验推出：写建议的默认模式是写通则，通则不需要事件。

2. **引用闭环**——决策时写 `<domain>#T<n>` → grep 汇总 → **决策卡按被引用次数排序** → 0 引用到期。
   这是唯一的**使用侧证据链**。它做了两个反直觉的替换：有效性从"自评"换成"被引用"；读什么从"我认为重要"换成"机械排序"。全文只有这一处能让"这东西到底有没有用"变成一个可查询的事实。

3. **价值位重定义 + 转正门槛**——"一致性 / 交接，不是单次会话质量升级器"；要"因它改变 ≥1 次"，声称"产出更好"须同任务对照。
   这是唯一的**判断标准**。它决定了这套东西会被继续投入还是被一句"感觉没变好"误杀——而误杀它的那个判据，恰恰是先验最默认的那个。

三者合起来是"写 / 用 / 判"三道闸，且有个共同点：**都不能靠先验想出，也都能被外部观察到。** 其余内容即便删光，这三样还在，essentials 就仍然是 essentials（可靠度声明是最接近第四样的东西，但它是这三者的一次性输出，不是独立机制）。
