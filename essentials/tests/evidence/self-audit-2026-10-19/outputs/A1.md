## ① 分诊结论

> **不造完整版；只造轻量版，并把它从「essentials 文档」改称为「强制程序清单」。**

按它自己的三问：

| 问 | 答 | 依据 |
|---|---|---|
| ① 该域有唯一公认写法吗？ | **没有**（但也几乎没有"不可检索"的部分） | 形态上 skill、AGENTS.md、ADR、checklist、eval 并存，确实无共识；但内容上"短、可执行、删过期、以行为变化而非文本存在为准"在 context-engineering 与 checklist 文献里已属公共知识 → 按它自己的准入三问，"查一下就有"→ 只配进「来源」节 |

→ **①过、②过、③不过 → 按它自己的分诊表：轻量版**（当场核证 + 记入任务笔记 + 一次可靠度声明），不建 `docs/scaffolds/`。

三点补充判断：

1. **③ 何时翻转成"大"**：agent 无人值守地跨会话、跨项目跑，或组织内 ≥3 个 agent 共享同一域——此时一个错判断会被当成常设权威反复复用，"静默扩散"成立，才够格造完整版。单人 + 作者在环，不够。
2. **它自断收益半径**：它为"跨会话/跨 agent 一致性"估值（定位第 2 条），却拒绝跨项目单源（复用 = 复制 + 重审）。所以它的一致性收益半径 = **一个项目**，这进一步压低 ③。
3. **若坚持造完整版，它唯一合法的身份是第③类（强制程序）**：它的内容 90% 是"标记、门槛、记录、到期删"这类不做会出事的动作，反先验事实 ≈ 0 条有来源、本地标定 ≈ 0 条有实测。它**不是**一份合格的 essentials 文档——按它自己的反凑数规则，它对自己应当"不收"。

## ③ 可证伪预测

我只给出三条，覆盖三类"删了可能真会变差"的裁决；纯重复删除（G 段 10 条、A/C 段合并项）我预测**无可测退化**，若出现退化说明重复项确有独立现场约束力，我的裁决错。

**预测 1 — 删「登记两行（L1 加载表）」会让脚手架变成只写不读**
- 行为变差：新会话进入弱领域时不再自动打开 `docs/scaffolds/`，文档从"决策时被引用"退化为"写的时候存在"，14 天后按到期删除被清掉——正是它自己列的反模式"只写不读的文件夹等于没搭"。
- 观察信号：接下来 3 次进入该域的新会话中，首轮读取 `docs/scaffolds/` 的比例（基线 ≥1/3）降到 0；或该文档「使用记录」在 14 天内新增 0 行。
- 证伪条件：3 次里 ≥1 次无需 L1 提示就被加载（靠触发词或 agent 习惯）→ 预测错，删除安全。

**预测 2 — 删「来源优先序 + 中英双语各搜一轮」会让来源构成退化**
- 行为变差：外部搜集退化为"搜到什么引什么"，官方规范/标准被博客转述和二手解读顶替——而"反先验事实"恰恰只能由一手来源推翻直觉。
- 观察信号：接下来 2 份新脚手架的「来源」节里，官方文档/标准占比 < 1/3，或二手解读（博客、论坛转述、AI 摘要）≥50%，或非中文来源 0 条而该域主文献为英文。
- 证伪条件：两份里一手来源仍 ≥2/3 且语种覆盖与删前一致 → 预测错。

**预测 3 — 删「反模式 10 条重复 + 反例 2/3」会让现场违规回流**
- 行为变差：上游规则（准入三问、证据判据、转正条件）都在**正文中段**，而反模式是**结尾的一屏禁令**。删掉后，读文档的人会跳过论证、只记住结构，违规率上升——即重复项有独立的"现场可见性价值"。
- 观察信号：接下来 5 份新脚手架中出现下列任一：① 「候选」条目被当结论引用；② 无来源条目进正文；③ 通用知识（"一页一结论"式）进正文——出现 ≥1 次即预测成立。
- 证伪条件：5 份全为 0 → 重复项确无独立作用，删除正确，也应把"反模式"这种体裁从 skill 里整体移除。

## ④ 这份 skill 最该保留的三样东西

1. **准入三问 + 三类（反先验 / 本地标定 / 强制程序）** — 唯一能把"判断文档"和"检索结果搬运"分开的装置。删了它，这份 skill 就只是一个文档模板加一堆语气坚定的禁令，和它要防的东西是同一类。
2. **证据判据（改进 = 结构/行为变化，术语出现不算）+ 反凑数（必须回指真实触发事件）** — 两条合起来是反自欺的最小闭环，也是全文唯一能被外人驳倒的地方。没有它们，"一致性""生长""转正"全变成不可证伪的自我表扬。
3. **使用记录 + 到期删除（0 触发即删）** — 唯一抗文档膨胀的机制，也是唯一能产出"本地标定"数据的机制。没有它，1 和 2 都只是口号；有了它，前两条才有反馈回路。

讽刺的是：这三样都属第③类**强制程序**。这份 skill 真正成立的形态，是一份**用来自我否证的强制程序清单**，而不是它所自称的那种"弱领域 essentials 文档"——按它自己的准入三问，它自己就是第一份应当被"不收"的稿件。
