# Macro Market Radar — 全球宏观市场雷达

## 定位

给用户一个**自上而下的全球市场环境快照**:不分析个股,而是回答"现在全球市场处于什么状态、哪里强哪里弱、今天为什么涨跌、有什么值得注意的信号"。

**架构原则: 数据源为辅, 搜索为主。**
免费行情接口 (akshare/东财) 在本机实测**不稳定** (请求一多会封 IP, 封禁期间所有接口失败)。因此本 skill 不依赖脚本拉全所有数据, 而是:
1. 脚本**尽力拉取**一次快照 (能拉多少是多少, 失败自动标记)
2. agent 看数据健康度标记, 对**缺失/过时**的部分用 **web_search 实时补充**
3. 融合成解读

## 何时使用

适合用户问:
- "今天全球/大盘怎么样?"
- "宏观环境如何? 现在风险偏好是高是低?"
- "港股/美股/A股最近强弱如何? 钱在往哪流?"
- "今天市场为什么涨/跌? 有什么关键消息?"
- "现在适合加仓/减仓/防守吗?"(提供环境判断, 不做个股推荐)

不适合:
- 问具体某只股票/某个板块深度 → 转个股/行业分析
- 需要分钟级盯盘/精确点位 → 本 skill 是宏观视角, 数据有延迟

## 数据模块与可靠性

| 数据模块 | 脚本源 | 备注 |
|---|---|---|
| 全球指数快照 (56个) | 东财 | 东财封禁时失败 → 搜索 |
| A股核心指数历史 (上证/深证) | 东财 → **新浪自动切换** | 有本地缓存, 一天拉一次 |
| 港股/日经/富时历史 | 东财 | 封禁时失败 → 搜索 |
| A股行业板块 (496个) | 东财 | 封禁时失败 → 搜索 |
| A股市场宽度 (涨跌/涨停/活跃度) | **乐咕 (独立源)** | 稳定 |
| 南北向资金 | 东财 | 封禁时失败 → 搜索 |
| 中国 PMI/GDP | 统计局 | 稳定 |
| 美股板块/当日新闻 | — | 无脚本源 → **搜索** |

**可靠性设计**: 指数历史有**本地缓存** (`.cache/`, gitignore, 一天一拉) + **失败冷却** (当天失败不重试); 数据源尽量多路冗余 (东财/新浪/乐咕/统计局), 单源故障不拖垮整体。

## 工作流

### Step 1: 尽力拉取数据快照

```bash
uv run --with akshare --with pandas python scripts/fetch_macro_data.py --format md
```

- `--format md` 输出可读 Markdown; `--format json` 输出结构化数据
- `--output FILE` 可指定输出文件
- 首次运行自动解析 akshare 依赖 (uv 临时环境), 无需全局安装
- 输出开头有**数据健康度摘要** (如 `全球指数快照=failed | 核心指数历史=2/6 ok`), 明确标出哪些需搜索补

### Step 2: 识别缺口, 用 web_search 补齐 (关键)

**先看数据健康度**, 凡标记 failed / 部分 ok 的, 都要搜索补。**搜索不是随便搜, 严格按 `references/information-sourcing-guide.md` 的方法**: 信息分级、交叉验证、区分盘中/收盘/复盘。

典型搜索 (时间 + 市场 + 关键词, 收评类等收盘后):

| 数据缺口 | 搜索词示例 |
|---|---|
| 全球指数快照失败 | `2026年9月X日 全球股市 收盘 美股 港股 欧股` |
| A股板块失败/需细节 | `2026年9月X日 A股 收评 板块 领涨 领跌` |
| A股情绪/涨停梯队 | `2026年9月X日 连板复盘 涨停` (连板网) |
| 美股当日板块/收盘 | `Sep X 2026 US stocks close sectors` / `财联社 美股收盘` |
| 当日关键新闻/涨跌原因 | `美股 今天 为什么 涨/跌`、`美联储`、`market today reason` |
| 宏观数据 (CPI/非农) | `美国 CPI 最新 公布`、先确认是否已发布 |

要求 (来自 information-sourcing-guide.md):
- **关键数字交叉验证 ≥2 个独立信源**, 对不上以一级源为准
- **区分盘中快讯与收盘定论**: 回答"今天哪个板块最强"必须用收盘/复盘源
- 给结论时**标注来源与时间**; 观点性内容注明"是谁的看法"
- 搜不到可靠数据就如实说, 不要编造

### Step 3: 融合解读 (核心)

把"脚本拉到的 + 搜索到的"合并, 按框架讲出有用信息:

1. **全球风险偏好总览**: 普涨还是普跌? 亚太/欧美/新兴谁强谁弱?
2. **跨市场强弱**: 结合 20/60 日 (脚本有则用, 无则搜索) 判断中期方向, 钱往哪流。
3. **板块结构**: A股领涨/领跌板块 (脚本或搜索), 判断资金在 A股内部流向哪条产业线。
4. **市场宽度/赚钱效应**: 看涨跌家数、涨停/跌停比、活跃度 (乐咕), 判断是普涨普跌还是结构性行情、情绪是亢奋还是冰点。
5. **资金面**: 看南北向资金 (脚本或搜索), 判断外资/内资动向 (南向大买港股 = 内资南下; 北向流入 A股 = 外资做多)。
6. **消息面催化**: 用搜索到的关键新闻解释"今天为什么涨跌", 挑真正影响市场的 2-4 条。
7. **宏观印证**: PMI/GDP/CPI 等是印证还是背离市场? 数据弱+股市涨 = 预期驱动, 提示脆弱性。
8. **风险/关注点**: 最值得盯的信号 (美元、BDI、超买超卖、政策时点)。

### Step 4: 给出结论

3-5 句话收尾, 融合**指数强弱 → 板块流向 → 消息面催化**三层证据, 给方向性判断, **不做个股/买卖建议**。

## 边界与不变量

- **不推荐个股**, 不做精确择时, 只描述市场环境与相对强弱。
- **数据有延迟与源误差**: 指数时间为各市场本地时间, 注意时区; 脚本数据与搜索数据冲突时, 以更新/更权威来源为准并说明。
- **免费接口不稳是常态**: 数据缺了就搜, 搜不到就明说, **绝不编数据**。
- **宏观数据更新频率低**: PMI/GDP 月/季度, 说明数据时点。
- **免责**: 仅供研究参考, 不构成投资建议。
