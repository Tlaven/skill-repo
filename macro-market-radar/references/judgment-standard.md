# 判断标准 (输出硬性规范)

> 本文件是 macro-market-radar 的**输出硬性标准**。任何一份输出 (含追问类回答) 违反本文件即视为不合格。
> **单一归属**: "判断标准"的**权威定义在本文件**; SKILL.md 与 interpretation-framework.md 只做**摘要 + 指针** —— 因为 SKILL.md 每次都会加载、references 按需加载, 摘要必须存在。**三处口径冲突时, 以本文件为准。**

## 0. 为什么必须有判断

本 skill 提供的是**决策需要的信息**, 不是数据搬运。用户读完必须知道"所以呢"。
只看描述、读完还要追问"那你觉得会怎样" = 本 skill 最常见的失败模式。

## 1. 判断要素 (前三项必填; 基准情景仅多情景时必填)

| 要素 | 要求 | 反例 |
|---|---|---|
| **方向** | 明确表态: 偏多 / 偏空 / 震荡 / 分化 (可附相对强弱排序) | "存在较大不确定性" |
| **时间窗 + 概率** | 标注期限 (未来 1-2 周 / 1-3 个月 / 年内) 与主观概率 (或区间; 区间须标为估计) | "中长期看好" (无期限、无概率) |
| **基准情景** | 多情景时必须标概率并指明哪一个是基准; 单一判断时可省略 | "情景 A/B/C 均有可能" |
| **证伪条件** | 可核对的数据/事件: 一旦发生即说明判断错误 | "需持续观察" |

## 2. 写法模板

> **判断**: 未来 {期限}, 我倾向 {方向} (主观概率 {X%})。
> **依据**: {1-2 个最强信号, 标来源与时间}。
> **基准情景**: {情景A}({概率}) > {情景B}({概率}) > {情景C}({概率})。
> **证伪**: 若 {可核对事件/数据} 出现, 本判断作废, 转向 {替代路径}。

## 3. 好 / 坏对照

❌ **坏 (只描述)**:
> 今日 A股普跌, 活跃度 5.8%, 南向资金转卖, 风险偏好收缩。数据时点 14:15, 不构成投资建议。

✅ **好 (描述 + 判断)**:
> 状态: 恐慌冰点 (活跃度 5.8%、跌停 28 家, 乐咕 15:00)。
> **判断**: 未来 1-2 周仍偏空 (~60%), 因加息定价与拥挤度未出清;
> **基准情景**: 继续磨底 (50%) > 利空出尽修复 (30%) > 单边加速下跌 (20%);
> **证伪**: 若成交量连续两日放大且指数站稳 5 日线, 看空判断作废。

## 4. 边界 (与免责的关系)

- **允许**: 方向判断、相对强弱排序、情景概率、时间窗、区间 (区间须标为估计)
- **禁止**: 个股推荐、精确点位择时、买卖指令、把判断写成事实
- **免责声明的正确位置**: 在判断**之后**, 用于说明数据边界与来源缺口;
  **不得**用"仅供参考 / 不构成投资建议"替代判断。**免责 ≠ 不判断。**

## 5. 自检清单 (输出前逐条核对, 任一不满足 = 本次输出不合格)

- 报告存在独立的"判断/预期"段, 且判断要素齐全: 方向 / 时间窗+概率 / 证伪条件 (**多情景时**另需"基准情景")
- 多情景时已标概率并指明**基准情景** (不是并列罗列)
- 每个关键数字有来源与时间; 每个观点注明"谁的观点"
- 用户问"所以呢?"能用一句话回答
- 数据缺失处: 标注缺口并**降低置信度**, 而不是放弃给判断

## 6. 追问类问题同样适用

用户问"为什么跌 / 未来会怎样 / 某行业怎么看 / 该不该担心 / 会不会加息"时:

- 描述层 (状态/数据) 可以压缩, 但**判断要素必给** (多情景时加基准情景)
- 行业/板块类问题: 给"赛道排序 + 驱动逻辑 + 时间窗 + 证伪条件", 不给个股
- 数据不确定时: 给判断 + 明确标注不确定来源, 不允许"因为不确定所以不表态"

## 7. 合理化借口 → 事实 (基线测试记录, 逐条预案)

下表左列是 agent 在**真实会话**里用来跳过判断的借口 (基线失败素材), 遇到时按右列处理, 不要重犯:

| 借口 (会这样说) | 事实 |
|---|---|
| "本 skill 是宏观视角, 只描述环境" | 宏观视角与给方向判断不冲突; **缺判断段 = 不合格** |
| "数据源不稳/有缺口, 没法判断" | 标注缺口 + 降置信度, **仍要给判断** (§5) |
| "情景 A/B/C 都列出来就够了" | 必须标概率并指明**基准情景** (§1) |
| "最后写了'不构成投资建议'" | 免责在判断**之后**, **不能替代判断** (§4) |
| "用户只问行情, 没问方向" | 一键触发默认必须含判断 (SKILL.md Step 4) |
| "用户说只要事实、别给建议" | 仍给**环境判断**; 只是不给个股/点位/买卖指令 (§4) |
| "先给数据, 结论等下轮/等用户追问" | 一键触发=一次跑完, 判断不留给用户催 |

**红旗 (出现即停, 重写收尾)**:
- 报告以免责声明结尾, 而不是以判断结尾
- 通篇只有"值得关注/需要警惕", 没有方向
- 判断写的是"中长期看好"这类**无期限、无概率**的话
- 列了多个情景, 却不标概率、不指基准情景
