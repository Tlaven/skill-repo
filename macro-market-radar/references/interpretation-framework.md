# 宏观解读框架

本 skill 的价值不在拉数据, 而在**把数据讲成有用的信息**。拿到 `fetch_macro_data.py` 的输出后, 按以下层次组织解读。

## 一、先看全局: 风险偏好 (Risk On / Risk Off)

看全球指数快照的**广度与方向**:

- **普涨** → 风险偏好回暖; **普跌** → 避险
- 数一下上涨 vs 下跌的指数数量, 比单看某个指数更能说明问题
- 特别关注**跨资产信号**: 美元指数、BDI(航运)、CRB(商品)的方向往往领先/印证股市情绪
  - 美元走弱 + 商品/新兴市场强 → 典型风险偏好回暖
  - 美元走强 + 商品弱 → 流动性收紧/避险

## 二、再看结构: 资金在流向哪里

对比核心指数的 **20日/60日涨跌幅**, 找相对强弱:

- **谁在领涨**: 60日最强的前 2-3 个市场 → 中期资金主线
- **谁在走弱**: 60日最弱的市场 → 回避/警惕
- **异常背离**: 当日大涨但 60日仍弱(反弹?) vs 当日小跌但 60日很强(回调?) → 需要提示, 勿把反弹当反转
- **区域对比**: A股 vs 港股 vs 美股 vs 亚太 vs 欧洲, 判断全球资金风格(如"港股强 A股弱"常反映南向/外资结构、"美股强全球弱"常反映美元流动性)

## 三、板块结构: A股内部的钱往哪流

脚本输出 A股领涨/领跌板块, 用来回答"指数背后是谁在动":

- **领涨板块属于哪类逻辑**?
  - 涨价/周期类 (农业、养殖、化工、有色) → 交易通胀/供给逻辑
  - 科技/成长类 (半导体、AI、软件) → 交易产业趋势/风险偏好
  - 防御类 (银行、公用、医药) → 市场偏谨慎
- **领涨 vs 领跌的板块特征**: 若涨的是防御、跌的是成长 → 指数可能没跌但内里在防守; 反之普涨且成长领涨 → 进攻性 risk-on
- **板块与指数的印证**: 深成指/创业板弱 + 领跌是科技成长 → 成长风格杀跌确认; 若指数弱但领涨是主题炒作 (小票) → 存量博弈、缺主线
- **结合宏观**: 养殖/农产品领涨常对应 CPI 回升预期; 基建/地产链弱对应内需疲软

## 四、关键新闻: 解释"为什么" (搜索驱动, 重点)

**本 skill 的实时信息主要靠 web_search, 而非脚本。** 脚本只给"是什么" (能拉到的涨跌), 不给"为什么"。分析时用 `web_search` 补:

1. **当日/隔夜全球市场关键事件**: 美联储利率/讲话、美国 CPI/非农、龙头财报、地缘、中国政策/数据、OPEC/大宗。用于解释涨跌催化。
2. **美股当日板块强弱**: 搜索"美股 板块 领涨 领跌"或 "US stock market sectors today"。
3. **脚本缺失的一切数据**: 先看脚本输出的数据健康度 (data_health), failed 的部分逐一搜索补上。

搜索技巧:
- 用**当天日期 + 市场**组合 (如 "2026年9月4日 美股 收盘") 提升时效
- 中文源搜 A股/港股/政策, 英文源搜美股/美联储/全球
- 关键数字 (指数点位、涨跌幅) 交叉验证两个来源再引用

要求:
- 给结论时**标注消息来源与时间**, 区分"已证实事件"和"传闻/预期"
- 不要罗列新闻, 只挑**真正影响市场**的 2-4 条, 并说清它影响了什么资产/为什么

## 五、找异常: 什么在变化

在表格里主动找**值得说一句**的数字, 而不是复述整张表:

- 涨跌幅绝对值大的(如单日 >2%, 或 60日 >10%)
- 明显偏离其近期常态的(如某指数 20日还在涨, 60日却转深跌 → 刚拐头)
- A股内部: 上证 vs 创业板/深成指的强弱差(风格: 大盘价值 vs 成长)

## 六、宏观印证: 数据与市场是否一致

用 PMI/GDP 验证市场定价:

- PMI **>50 扩张 / <50 收缩**; 看最新值 + 环比方向
- 宏观数据是**滞后确认**还是**领先背离**:
  - 经济数据走弱 + 股市上涨 → 预期驱动(政策/流动性), 需提示"基本面尚未兑现"
  - 经济数据走强 + 股市下跌 → 可能是利率/估值问题, 而非盈利问题
- 注意数据时点: PMI 是上月、GDP 是上季, 解读时说明"这是 X 月/季度的数据"

## 七、输出结论

用 3-5 句话收尾, 结构建议:

1. **一句话定调**: "当前全球处于风险偏好回暖/分化/避险状态"
2. **证据**: 引用 1-2 个最强信号(如"港股 60日 +5%, 全球领涨")
3. **结构判断**: "钱在流向 X, 离开 Y"
4. **风险/关注点**: "最需要盯的是 Z"
5. **边界**: "以上为环境描述, 不构成买卖建议"

## 示例(基于实测数据形态)

> 今日港股、亚太领涨(恒指 +1.8%, 日经 +1.3%), A股走弱(上证 -0.5%, 深成指 -1%), 美股前一日收涨。60日维度港股 +5.2% 显著强于 A股(深成指 -9.1%), 呈"南强北弱"格局。中国官方 PMI 49.8 仍处收缩区间但边际改善, GDP 上半年 +4.7%。解读: 全球风险偏好回暖但结构分化, 资金偏向港股/亚太, A股成长风格中期承压; 宏观基本面偏弱但市场在交易预期, 需警惕预期差。

## 避坑

- 不要把 56 个指数全念一遍 —— 用户要的是提炼
- 不要因为某天普涨就说"牛市来了", 结合 60日趋势看是反弹还是反转
- 不要给个股/板块买卖指令, 本 skill 只描述环境
- 永远标注数据时间点, 避免把隔夜美股当成"今日 A股"语境混淆
