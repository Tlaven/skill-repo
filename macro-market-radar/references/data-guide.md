# 数据源与字段说明

本 skill 的数据来自 AKShare 开源接口, 全部免费、无需 key。

## 接口清单

### 1. 全球指数实时快照

**接口**: `ak.index_global_spot_em()` (东财)

返回约 56 个全球主要指数的实时/最新行情, 覆盖:
- 亚太: 上证指数、深证成指、沪深300、创业板指、恒生指数、国企指数、红筹指数、日经225、韩国KOSPI、台湾加权、印度SENSEX、澳洲标普200、新加坡STI、泰国SET、越南胡志明等
- 欧美: 道琼斯、标普500、纳斯达克、英国富时100/250、德国DAX30、法国CAC40、欧洲斯托克50、瑞士SMI、荷兰AEX、西班牙IBEX35、意大利MIB、加拿大TSX、巴西BOVESPA、墨西哥BOLSA、俄罗斯RTS等
- 其他: 美元指数、波罗的海BDI、路透CRB商品指数

**关键字段**: `名称` / `代码` / `最新价` / `涨跌幅` / `最新行情时间`

**注意**: `最新行情时间` 为各市场本地时间, 解读时注意时区差异(美股通常显示美东前一日收盘)。

### 2. 核心指数历史(用于区间涨跌幅)

**接口** (脚本内已做双源冗余 + 本地缓存):
- A股指数: `ak.stock_zh_index_daily_em` (东财) 失败 → 自动切 `ak.stock_zh_index_daily` (新浪, 独立通道)
- 全球指数: `ak.index_global_hist_em(symbol="恒生指数")` (东财, 仅此一源)

**本地缓存** (`.cache/index_history.json`, gitignore):
- 每个指数**一天只拉一次全量**, 存最近 400 行; 当天后续运行直接命中缓存 (0 请求)
- 拉取失败的指数记 **失败冷却** 标记, 当天不再重试 (避免东财封禁时反复退避耗时)

脚本对每只核心指数计算 **1日/5日/20日/60日涨跌幅**, 用于识别短期动量与中期趋势。

核心指数清单:
- A股: 上证指数(sh000001)、深证成指(sz399001) — **双源可用**
- 港股: 恒生指数、国企指数 — 仅东财
- 亚太: 日经225 | 欧洲: 英国富时100 — 仅东财
- (美股三大指数不做历史请求以降低封禁风险, 当日涨跌由 spot 覆盖, 区间趋势靠搜索)

> 如需扩展全球指数, 可用 `index_global_spot_em()` 返回的 `名称` 列对照添加, 但需逐个验证历史接口接受的确切名称。

### 3. A股行业板块强弱

**接口**: `ak.stock_board_industry_name_em()` (东财)

返回全市场 **496 个行业板块**, 关键字段:
- `板块名称` / `涨跌幅` / `总市值` / `换手率`
- `上涨家数` / `下跌家数`
- `领涨股票` / `领涨股票-涨跌幅`

脚本聚合输出: 板块总数、上涨/下跌板块数、**领涨前 8**、**领跌前 5** (含领涨/领跌股), 用于判断 A股内部资金流向哪条产业线。

**注意**: 该接口较慢 (约 4s) 且受东财限流影响, 脚本已纳入全局节流与重试。

### 4. A股市场宽度 / 赚钱效应

**接口**: `ak.stock_market_activity_legu()` (乐咕, **独立于东财, 稳定**)

返回全市场宽度与情绪:
- 上涨 / 下跌 / 平盘家数
- 涨停 / 真实涨停 / 跌停 / 真实跌停家数
- 活跃度 (%)
- 统计日期

脚本据此自动计算 **涨跌比** 和 **涨停/跌停比** 两个情绪信号。解读: 涨跌比 <1 但涨停多 = 结构性行情; 涨跌比极低 + 跌停多 = 恐慌; 活跃度高 + 普涨 = 情绪亢奋。

### 5. 沪深港通资金 (南北向)

**接口**: `ak.stock_hsgt_fund_flow_summary_em()` (东财)

返回沪股通/深股通(北向)与港股通沪/深(南向)的:
- 成交净买额、资金净流入
- 对应指数当日涨跌幅
- 上涨/下跌家数

**注意**: 北向资金自 2024-08 起盘中数据停止披露 (可能显示 0); 南向资金 (港股通) 是判断"内资南下买港股"的关键, 港股强势时常伴随南向大额净买入。

### 6. 宏观指标

| 显示名 | 接口 | 频率 | 数据源 |
|---|---|---|---|
| 中国官方制造业PMI | `ak.macro_china_pmi()` | 月 | 国家统计局 |

## 已知不稳定的数据源 (勿依赖)

以下接口在实测中经常返回空/报错, **脚本已排除或容错**:
- `macro_usa_*` (美国CPI/非农/ISM等) — 走金十数据源, JSON 解析不稳定
- `macro_china_cpi_yearly` — 同上

如需美国宏观数据, 建议:
1. 用 yfinance 拉取经济指标 ETF/利率 (如 `^TNX` 十年期美债收益率)
2. 或让 agent 用 web_search 查最新公布值并注明来源

## 美股板块与当日新闻: 无稳定脚本源, 靠 agent 搜索

- **美股板块**: akshare 无现成的美股行业板块接口; yfinance 在本机实测会被限流 (YFRateLimitError)。需要判断美股当日板块强弱 (科技/能源/金融/医疗等) 时, 用 `web_search` 搜当日美股板块表现。
- **当日关键新闻**: 脚本不拉新闻 (快讯源时效强但杂乱)。分析时用 `web_search` 搜当天影响全球市场的关键事件 (美联储、龙头财报、地缘、中国政策), 以解释涨跌动因。

## 网络环境适配与可靠性说明 (重要)

脚本启动时自动: 清理 `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY` 环境变量 + 设 `NO_PROXY=*` (本机 Clash 等本地代理会挡东财接口)。

**但免费接口 (东财) 实测不稳定**: 短时间内连续请求 (约 10+ 次) 会触发 IP 封禁, 封禁期间**所有**东财接口 (含单发) 都返回 `RemoteDisconnected`, 可能持续数分钟到数十分钟。因此:

- 脚本刻意**减少请求量**: 核心指数历史只保留 6 只 (去掉美股 3 只), 并全局节流 + 指数退避
- **A股历史双源冗余**: 东财被封时自动切新浪 (`stock_zh_index_daily`), 实测可用
- **本地缓存 + 失败冷却**: 一天一拉 + 当天失败不重试 (详见第 2 节)
- 乐咕源 (`stock_market_activity_legu`) 独立于东财, 封禁期间仍稳定可用
- 脚本输出**数据健康度摘要** (`data_health`), 明确标记每块数据 ok/failed
- **任何 failed 的数据块都不要重试硬拉, 改用 web_search 补** — 这是本 skill 的既定策略
