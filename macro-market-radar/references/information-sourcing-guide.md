# 宏观信息获取与验证指南

> 目的: 解决"信息来源窄、容易被单一渠道带偏"的问题。
> 原则: **结论必须来自多个独立信源的交叉验证; 永远区分"事实"与"观点"、"实时"与"收盘"、"已证实"与"传闻"。**

## 一、信息源分级 (按可信度)

### 一级: 原始数据 / 官方 (最可信, 用于锚定"是什么")
- **交易所/官方**: 沪深交易所公告、港交所、SEC (美股)、国家统计局 (宏观)
- **行情接口**: akshare 脚本拉的指数/板块/资金 (东财/新浪/乐咕), 是"数字锚"
- 用途: 涨跌幅、点位、成交额、官方经济数据 — 这些**必须**来自一级源, 不靠二手转述

### 二级: 权威财经媒体 (可信, 用于"发生了什么")
- 财联社/电报、华尔街见闻 (快讯最快)
- 东方财富、新浪财经 (收评/数据汇总全)
- 央广网/新华/上证报 (政策与官方定调)
- Reuters/Bloomberg/CNBC (全球)
- 用途: 事件、政策、公司公告解读、市场收评

### 三级: 专业复盘/社区 (部分可信, 用于"市场怎么看")
- 连板网 (涨停梯队/情绪冰点温度计, 结构清晰)
- 雪球复盘专栏、52打板网 (盘面解读, 但带作者立场)
- 用途: 情绪判断、题材主线识别 — **只取事实部分, 观点要打折**

### 四级: 自媒体/传闻/预测 (不可信, 仅线索)
- 各种"大师预测""内幕" — 不作为依据, 最多当搜索线索

**铁律**: 越往下的信源, 越只能用于"找线索/看情绪", 不能用于"下结论"。结论的**事实底座**必须是一级+二级。

## 二、去哪找 (按市场/主题)

| 要查什么 | 首选信源 | 备选 |
|---|---|---|
| A股板块/个股涨跌 | akshare 脚本 | 东财行情 |
| A股涨停梯队/情绪 | 连板网 (搜 "连板复盘 日期") | 东财涨停池 |
| A股当日复盘 (为什么涨跌) | 财联社电报 / 东财收评 | 雪球复盘 (注明作者) |
| 港股/南向资金 | akshare 南北向接口 | 财联社 |
| 美股收盘/板块 | 财联社美股收盘 / CNBC | 新浪财经美股 |
| 全球隔夜市场 | 华尔街见闻 / 财联社 | 英为财情 |
| 美联储/政策 | 官方声明 / Reuters | 财联社解读 |
| 宏观数据 (CPI/非农/GDP) | 官方统计局 / BLS | 一级源优先, 见下 |
| 大宗/航运 (BDI/原油) | 东财 (脚本 spot 含 BDI/CRB) | 英为财情 |

**重要**: 搜索引擎结果里的"快讯站" (如新浪财经滚动、东财个股页) 常是**同一个原始来源的多次转载**, 看起来来源多, 实际是同一信息 — 不算交叉验证。

## 三、搜索方法论 (怎么搜才不窄)

### 1. 用"时间 + 市场 + 关键词"锁定
- `2026年9月4日 A股 收评 板块` / `Sep 4 2026 US stocks close sectors`
- 收评/复盘类文章在收盘后 (A股 15:00 后、美股美东 16:00 后) 才有, 盘中搜到的是快讯/半场, **要区分时点**

### 2. 主动搜"反面/不同说法"
- 不只搜 "领涨板块", 也搜 "领跌 原因" "冲高回落 原因" — 涨跌是同一枚硬币
- 看多/看空两种解读都看, 再判断哪边证据硬

### 3. 用"来源词"限定可信度
- 搜 `site:` 语法对 agent 不一定可用, 但可在关键词里加来源名: `财联社 收评`、`Reuters Fed`、`连板网 复盘`
- 政策/宏观: 直接搜官方名 (`国家统计局 PMI`、`Federal Reserve statement`)

### 4. 每个关键数字交叉验证 ≥2 个独立信源
- 指数涨跌幅: akshare 数字 vs 财联社收评数字 vs 新浪 — 至少两个对上才引用
- 对不上时: 以一级源 (官方/行情接口) 为准, 并说明差异

## 四、区分: 实时 vs 收盘 vs 复盘 (最常见的坑)

| 类型 | 何时出现 | 可信度 | 用途 |
|---|---|---|---|
| **盘中快讯** | 交易时段 | 事实但**不完整** | 只能当"正在发生什么", 不能当"今天怎样" |
| **收盘定论** | A股 15:00+ / 美股美东 16:00+ | 高 | "今天涨跌如何" 的唯一依据 |
| **收盘复盘** | 收盘后数小时 | 中 (带解读) | "为什么涨跌、主线是什么、情绪如何" |
| **隔夜外盘** | A股开盘前 | 高 (已收盘) | A股开盘情绪的重要参考 |

**实战教训** (2026-09-04): 若只看盘中快讯, 会得出"黄金/电力/服务器领涨" (早盘), 而**收盘实际是猪肉/养殖逆势领涨、科技被闷杀** — 盘中与收盘可以完全相反。**给用户的"今天哪个板块最强"必须用收盘/复盘信源, 不能用盘中快讯。**

## 五、宏观数据的时点意识

- 中国 PMI/GDP: 统计局每月/每季固定发布, **滞后** (PMI 是上月、GDP 是上季)
- 美国 CPI/非农: 有固定发布时间表 (通常美东 8:30), 搜时注意是否已发布
- 搜索宏观数据时: 先确认"最新一期是哪个月/季度的、是否已公布", 再引用数值, 避免用过时数据
- 官方源优先: 国家统计局 / BLS / ECB 等, 二手转述可能出错

## 六、输出时如何交代来源

每次给结论, 在关键事实上标注:
1. **数据点** (如"上证 -0.3%") → 来自哪个信源 + 什么时间
2. **事件** (如"美联储转鸽") → 媒体名 + 是否官方证实
3. **解读/观点** → 说明是"谁的看法" (某复盘作者), 不是事实
4. **无法验证** → 明说"此数据未能交叉验证", 不编造

> 一句话收尾: **数字靠脚本和官方, 事件靠财联社/Reuters, 情绪看连板/雪球但要打折, 盘中快讯不当收盘结论, 每个关键结论至少两个独立源。**
