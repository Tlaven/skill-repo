# 每日宏观覆盖清单 (Daily Coverage Checklist)

> 目的: 让"一键跑市场雷达"的**信息收集范围固定**下来, 不依赖 agent 临场决定该搜什么。
> 用法: 每次执行本 skill 时, 先跑数据快照脚本, 然后**逐项过这份清单**——缺的用 web_search 补, 已有的标记跳过。这份清单保证"新闻收集"不再靠用户追问。

## 0. 先定市场时点 (每次必做)

北京时间是锚, 决定"看哪天的收盘/盘中":

| 北京时间 | A股/港股 | 美股 | 欧洲 | 日经 |
|---|---|---|---|---|
| 09:30–15:00 | **盘中** (看实时) | 隔夜收盘 | 隔夜/盘中 | 盘中/收盘 |
| 15:00–21:30 | **当日已收盘** (看收评) | 隔夜收盘 (当日晚间看盘前) | 盘中 | 已收盘 |
| 21:30–次日04:00 | 已收盘 | **盘中** (看实时/盘前) | 已收盘 | 已收盘 |
| 次日04:00–09:30 | 未开盘 | **已收盘** | 已收盘 | 未开盘/盘中 |

**铁律**: 回答"今天哪个板块最强/为什么涨跌"必须用**收盘/复盘源** (A股 15:00+ 收评、美股美东 16:00+ 收盘), 不能用盘中快讯。收盘复盘类文章在收盘后数小时才出现。

## A. 每日固定收集项 (不管数据脚本成败都要过一遍)

> 优先级从高到低。凡是脚本 `data_health` 已标记 ok 的数字, **不必重复搜** (脚本数字是一级源), 但**新闻和"为什么"永远要搜**。

### A1. 隔夜美股收盘 (每天必看, 全球风险偏好锚)
- **第一步: 锚定美东最新交易日是哪天** (是否隔夜休市/美股节假日, 如劳动节)。
  中文源的时间戳基于北京时间, 可能比美东早 12 小时 → 标题"9/4大涨"可能是美东 9/3 的行情。
  引用任何收盘数字前, 先确认"这个数字属于哪个美东交易日", 再判断是不是"隔夜"。
- 三大指数 (道指/标普/纳指) 收盘涨跌 + 点位
- **领涨/领跌板块** + 催化 (收益率、美元、美联储讲话、龙头财报)
- 美债收益率 (10Y) 方向、美元指数方向
- 搜索词: `Sep X 2026 US stocks close Dow Nasdaq S&P 500` / `美股 收盘 板块` / `财联社 美股收盘`
- 来源: WSJ/CNBC/MarketWatch/Investopedia (英文), 财联社/新浪美股 (中文)

### A2. 当日 A股收盘 (北京时间 15:00 后看收评)
- 上证/深成/创业板 收盘涨跌
- **领涨/领跌板块** (脚本有则用, 无则搜) — 必须收盘源
- 成交额、涨跌家数、涨停/跌停 (脚本 market_breadth 覆盖)
- 搜索词: `2026年X月X日 A股 收评 板块 领涨 领跌` (加"收评"防垃圾结果)
- 情绪/梯队: `2026年X月X日 连板复盘 涨停` (连板网) — 判断情绪冰点/亢奋
- 来源: 财联社/东方财富收评/新浪财经; 连板网、52打板网 (只取事实)

### A3. 当日港股收盘 (南向资金是关键)
- 恒指/恒生科技/国企指数 收盘涨跌
- **南向资金** 净买入 (脚本 hsgt_flow 覆盖; 港股强势常伴南向大买)
- 领涨板块/题材 (科网/AI/金融/地产等)
- 搜索词: `2026年X月X日 港股 收盘 恒生指数 南向资金`
- 来源: 新浪港股收评/东方财富港股/财联社

### A4. 关键新闻 (挑真正影响市场的 2-4 条, 不是罗列)
新闻是"为什么涨跌"的核心, 永远要搜。按影响级别找:
1. **央行/利率**: 美联储 (FOMC 日历、主席/理事讲话鹰鸽)、欧央行/日央行
2. **中国政策/资金**: 国常会/部委新政、政策性金融工具、证监会监管动向
3. **地缘/大宗**: 中东/俄乌、油价、金价、BDI (航运)
4. **龙头财报异动**: 前一天盘后/当天盘前的重大财报
5. **宏观数据**: 当天发布的 PMI/CPI/非农/GDP
- 搜索词: `财联社 2026年X月X日 要闻 政策` / `market today reason` / `美联储`
- 来源: 财联社电报 (最快)/华尔街见闻/Reuters/Bloomberg
- **给结论时标注来源与时间; 观点性内容注明"是谁的看法"**

### A5. 市场时点特殊日子 (触发额外核对)
> 每次先看今天/本周落在哪个窗口, 决定要不要重点盯某个数据:

| 时间窗口 | 要核对什么 |
|---|---|
| **每月第一个周五** | 美国非农 (北京时间当晚 20:30 公布) — 9/15-16 FOMC 前最重要 |
| FOMC 会议 (9/15-16, 11月, 12月) | 会前两周是"加息/降息预期博弈"窗口, 官员讲话密集 |
| 月初 (1-5日) | 各国 PMI 密集发布; 美国 ISM |
| 月中 (10-15日) | 美国 CPI/PPI; 中国宏观数据窗口 |
| 每季度末 | GDP、季度末资金面/调仓 |
| 财报季 (1/4/7/10月中起) | 龙头财报是当日美股最大变量 |

## B. 数据缺口补充 (脚本 failed 的部分)

先看脚本输出的 `data_health`, 凡 failed / 部分 ok 的都按此补:

| 数据缺口 | 搜索词示例 |
|---|---|
| 全球指数快照失败 | `2026年X月X日 全球股市 收盘 美股 港股 欧股` |
| A股板块失败 | `2026年X月X日 A股 收评 板块 领涨 领跌` (加"收评") |
| 港股/日经/富时失败 | `2026年X月X日 港股 恒生指数 收盘` / 换 tradingeconomics |
| 美股板块 | `Sep X 2026 US stocks sectors` / `美股 板块 领涨` |
| 宏观数据 | `美国 CPI 最新 公布` (先确认是否已发布、是哪一期) |

**每个固定项的首选源 (直接搜这个, 别宽泛搜)**:
- A3 港股/南向: `财联社 港股 收评` / 新浪港股收评页 (宽泛搜"港股 收盘"易命中边角无关页)
- A股板块/PCB 等题材: `东方财富 收评 PCB` / `21财经 PCB 涨价` / 连板网 lianban.net
- 隔夜美股: BLS 官方 (锚定非农/失业率数字) → CNBC/WaPo → 中文源仅作二次确认
- 若首选源搜索仍被无关页填满, 直接 web_fetch 兜底页 (见上表), 不要在同 query 上耗 ≥2 次

**搜索失败升级路径** (不要反复重试同一 query):
1. query 加来源词/收评词 (如 `A股 收评`、`财联社`、`Sep X 2026 US stocks close`)
2. 换语言/措辞重述 (`美股 为什么 涨` vs `美股 三大指数 收涨`)
3. web_fetch 兜底页: 财联社主题页 `cls.cn/subject/7373` (美股)、`readmarkets.com/market`、连板网 `lianban.net/days/YYYY-MM-DD.html`
4. 都拿不到 → **如实说"未能交叉验证", 不编造**

## C. 交叉验证要求 (每次收尾前检查)

- 关键数字 (指数涨跌/点位) ≥2 个独立信源, 对不上以一级源 (脚本/官方) 为准并说明
- 区分: 盘中快讯 ≠ 收盘定论; 已证实事件 ≠ 传闻/预期; 事实 ≠ 观点
- 搜索引擎里"快讯站大量转载同一来源"不算交叉验证
- 判断是反弹还是反转: 看 20/60 日趋势, 别因单日大涨下结论
