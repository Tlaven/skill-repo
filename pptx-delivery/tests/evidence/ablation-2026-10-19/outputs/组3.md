## 前提假设(影响后面所有数值)

- **场景判定**:内部工程评审 + 会后会被单独转发 → **阅读型为主、投影兜底**。16:9,正文 16pt、行距 1.4(不是放映型的 24pt 起)。
- **画布** 1920×1080;安全区左右 96、上 80、**底部锚线固定 y=1000**。
- **间距只取 8 的倍数六档**:8 / 16 / 24 / 32 / 48 / 64 / 96。同角色同值,组内距 < 组间距。
- **字号八档,一档一角色**:11 注脚/锚线 · 14 表格与等宽 · 16 正文 · 20 区块标题 · 24 组标题 · 32 结论句 · 40 仅 P8 判词 · 96 仅 P5 大数字("只用一次"也是规则,不许出现第二次例外)。

- **收口**:每页 y=1000 一条 1pt 锚线 + 左注脚 11pt + 右页码 11pt,8 页同款同高。
- **页型序列**:封面 → 图+解读 → 3×3 矩阵 → 双栏 → 记分卡 → 流程 → 表格 → 行动项。无同型相邻,无连续 3 页同型。

## 二、三个最容易做错的视觉 / 版式判断

**1. C1–C9 到底该做成"九个等权卡片"还是"三层矩阵"**
- 错法:九宫格平铺九张同尺寸卡片——九个都重要等于没有重点,且 9 块直接越过了"KPI ≤6"的容量上限。
- 选择:3 行 × 3 列的矩阵,行标题改写成三个问题(能不能改 / 对不对眼 / 会不会穿帮)。
- 理由:容量规则约束的是**读者要同时拿住的块数(3 个)**,不是画面上的矩形个数;编号仍连续到 C9,一条断言不丢。

**2. 负控页该不该画柱状图**
- 错法:把 7 个缺陷的命中率画成七根柱——全是 100%,等高,零方差,图表只证明了"都一样"。
- 选择:两个 KPI(7/7、0)+ 一条 7 格证据条带,条带只承担"逐个点名"的举证功能。
- 理由:这页的论点是"检查器可信",不是"命中率分布";数字要少而大,证据要具体到 D1–D7。

**3. 阈值表与目检盲区:拆两页,还是同页上下分区?红黄绿灯要不要上?**
- 错法:9 条断言全列(超 8 行)+ 红/黄/绿三色标签——语义色一旦装饰化,真正的 FAIL 就跳不出来了。
- 选择:C8/C9 合并成末行压到 8 行;级别只用实心/空心方块 + 文字;盲区另起一条独立横带,不拆页。
- 理由:表与盲区是同一个判断的两面("可断言的边界在哪"),拆页会把盲区降级成第二个次要信息,正好丢掉最该被看见的部分。

## 三、交付前我会跑的 3 个检查(可判定)

**检查 1|刻度与间距一致性**
- 断言:全部形状满足 `x % 8 == 0 and y % 8 == 0 and w % 8 == 0 and h % 8 == 0`;任意相邻两元素的间距 ∈ {8,16,24,32,48,64,96};同一角色(页边距 / 区块间距 / 块内行距 / 栏间距)在 8 页里**取值只有 1 种**。
- 判定:违规计数 = 0 才放行。任何一个"手动微调 2px"即 FAIL。

**检查 2|文本层级与结论句**
- 断言:`set(font_sizes) ⊆ {11,14,16,20,24,32,40,96}`,且每个字号映射到唯一角色(11 注脚/锚线,14 表格与 mono,16 正文,20/24 标题,32 结论句,40 仅 P8,96 仅 P5);8 页每页**有且仅有 1 条** action title,以「。」结尾、≤32 字;单页正文文本块 ≤6,正文字数 ≤250。
- 判定:字号越界 / 一号多角色 / 标题超 32 字 / 满页文字,任一命中即 FAIL。

**检查 3|语义色、收口与页型序列**
- 断言:非调色板填充数 = 0;红色像素只出现在 P2 的 3 个圈注与 P5 的缺口标记(当前应为 0 处),绿色只出现在 P5 的命中标记;8 页底部锚线 y 坐标完全相同、注脚字号 = 11pt;版式类型序列相邻两页不同、任意连续 3 页互不相同。
- 判定:以上全部为真方可导出;追加一条渲染层复核——8 页导出 PNG 逐页比对源页,缺字 = 0、压字 = 0、出画布 = 0(C7/C8 的人工兜底)。
