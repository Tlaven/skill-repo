# 版式决策卡(从 slide-patterns-essentials 提炼)

1. 先写结论句标题(完整句、带判断);写不出 = 内容没想清,不排版。
2. 一页一信息;第二论点另起页。
3. 选原型(大数字 / 柱图 / 图+解读 / 双栏 / 三支柱 / 流程 / 瀑布 / 漏斗 / 2×2 / 记分卡 / 引用+证据 / 时间线 / 仪表盘 / 执行摘要);一页不混两型;同型不连排(连续 ≥3 页不同型)。
4. 容量:流程 ≤5 步;KPI ≤6 块;表格 ≤8 行;超限拆页 / 附录。
5. 三层分离:信息层(结论 + 证据) / 图解层 / 氛围层;氛围层不放任何文字。
6. 数据页:图 + 解读框(指向具体数据点);比较用柱,不用饼 / 面积。
7. 引用页:quote + evidence 配对。
8. 收尾给行动项 / 清单指针,不写"谢谢"。
9. 红线:全篇一种网格、12 步流程图、满页文字——重排。
