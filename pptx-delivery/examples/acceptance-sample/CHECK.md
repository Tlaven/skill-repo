# 检查指引 — 亲手验收这份示例(13 页 · 每页 ≥3 模块)

> 这是一份**参考示例交付包**(非测试夹具):`deck.pptx` + 渲染图 + QA 证据 + 本指引。
> 目的:让你亲手确认「生成 → 断言 → 渲染复验 → 验收清单」这条链是真的;版式判据见 `../../docs/scaffolds/slide-patterns-essentials.md`(v0.1:丰富 = 单页组件密度 × 信息具体度)。

## 0. 这 13 页各自由什么组成

| 页 | 模块组成(除章节栏 / 页码 / 底锚线外) | 看什么 |
|---|---|---|
| 1 | 点阵纹理 + 环形装饰 + 三条数据 chip + 版本号 | 氛围层不承载信息、对比度合规 |
| 2 | 三栏(现状/做法/结果)+ 底部 4 格数字带 | 栏内三句封顶;数字带独立成组 |
| 3 | 3×3 编号瓦片 + 右侧阈值/来源栏(带分隔线) | 编号徽章是形状组件;阈值有来源 |
| 4 | 4 chevron + 产物 chip + 5 行"步/命令/失败时"表 | 四步顺序;表格列对齐 |
| 5 | 阶段标签 / 主线与圆点 / 名称与说明 / 标签层(四层) | 终点高亮;层与层不混 |
| 6 | 环形图 + 图例 + 6 个 KPI 瓦片(含迷你条)+ 底部双栏 | 红色瓦片只放"要盯的那一个" |
| 7 | 2×2 轴 + 4 象限贴片 + 象限注释 + 轴标签 | 轴与注释成对 |
| 8 | 双栏对比 + VS 徽章 + 底部 4 组证据数字 | 两侧行对齐 |
| 9 | 10 行记分卡(表头 + ●/○ 计量 + 说明) | 粗颗粒记分,不做假精度 |
| 10 | 大字引用 + 右侧两组数字 + 来源行 | quote + evidence 必须配对 |
| 11 | 终端窗口 + 5 条命令 + 3 条注释 + 产物 chip 行 | 顺序 = 依赖关系 |
| 12 | 6 色块(hex + 角色)+ 角色用量表 + 对比度注 | 一套颜色三个角色 |
| 13 | 标题 + 3 条要点 + 3 个行动 chip | 收尾给行动项,不写"谢谢" |

## 1. 打开来看(观感与可编辑性)

用 WPS / PowerPoint 打开 `deck.pptx`,逐页对照:

- [ ] 每页都能直接改文字、移动形状(不是整页图片)——对应 C9 可编辑性;
- [ ] 每页至少 3 个模块同时在场(章节栏 / 页码 / 锚线 / 主模块组),不是大留白极简页;
- [ ] 标题与正文左缘同一条线(0.8");内容页底锚线同一高度(≈6.25"),封面 / 收尾页页脚 6.6";
- [ ] 颜色只有规定角色(第 12 页):标题 `1E2761` / 正文 `222222` / 说明 `5F6B7C`(深底页白 / `CADCFC`);
- [ ] 装饰件(点阵、环、箭形、迷你条、徽章)都是形状或图片,**不是文字**;
- [ ] 图片"替代文字"是描述(右键图片 → 查看替代文字)。

## 2. 看渲染图与 PDF(导出保真)

- [ ] 打开 `render/slide-01..13.png`(或 `render/deck.pdf`),与直接开 PPTX 的观感一致;
- [ ] 第 9 页记分卡的 ●/○ 字形导出后仍完整(对应 C8);
- [ ] 第 6 页环形图 1:1、第 1 页点阵 16:9,均无变形(对应 C6);两张图片都在(对应 C1)。

## 3. 亲手跑机器断言(一条命令,预期全绿)

在 pptx-delivery 目录下:

```powershell
python scripts/qa_check.py examples/acceptance-sample/deck.pptx --pdf examples/acceptance-sample/render/deck.pdf --strict --expect-slides 13
```

预期:每个检查输出 info,`summary: errors=0, flags=0`,退出码 0(JSON 证据在 `qa/deck-pdf.json`)。

- [ ] **可选挑战(证明它真会红,不是恒绿)**:把 PPTX 里任意一个文本框字号改成 8pt,另存一份,再跑一遍——应出现 `C3-min-font` 的 FLAG 且退出码变 1;改回后恢复全绿。
