## 0. 口径与方法(先说清"怎么量的",再说"看到什么")

| 项 | 说明 |
|---|---|
| 像素→物理量 | 渲染图为 16:9 全页 1920×1080,对应 13.333×7.5in → **144 px/in**,**1pt ≈ 2px**;0.5in = 72px,0.3in = 43px。下文"in"均由 px/144 换算。 |
| 版式量测 | 逐行/逐列"墨迹投影"求行波段(`profile.py:bands()`),阈值 = 与背景色的通道差之和 > 36(抗 JPEG 噪声)。定位了每页每个文字块/图形块的 y 波段与 x 波段。 |
| 颜色量测 | 取区域内"墨迹像素中最深的 20%"的均值作字形本色(`color.py:core_ink()`),再按 WCAG 相对亮度算对比度(`color.py:ratio()`)。 |
| 字号折算 | 用 **Latin 大写帽高 ≈ 0.72em** 折算(如 p6 bullet 的 "JSON" 帽高 23px → em≈32px → ≈16pt);纯中文行用墨高/字号比折算,并**只用同字符串跨页比**(与字体无关,最可靠)。绝对 pt 为**估算值**,标 ±1pt。 |
| 弱元素扫描 | 额外用 8 < 通道差 ≤ 36 的"弱墨"带扫全页(逐行 + 逐列),排查低透明度形状/阴影/极淡文字是否被强阈值漏掉。 |
| 字形边距的前置结论 | 实测同页 12pt 中文/拉丁的"字盒边距"仅 0–2px,28pt 标题 ≤5px——因此下文 15–20px 的位置差**不是**字形边距造成的,是版式结构差。 |
| 做不到的 | 无 .pptx、无 PDF:不能核 XML 字号/颜色码/占位符字符串、不能核 PDF 文本层(C8)、不能核"可编辑性"(C9)、不能核元数据/隐藏页/备注(L3)。下文相关处一律标"看不出来",不折算成结论。 |

## 4. 盲区与"看不出"清单(诚实声明)

1. **无 XML / 无 PDF**:C1(页数/媒体清点)、C2(占位残留在 XML 层的模式匹配)、C3(字号读值)、C4(颜色卫生)、C5(工具测的对比度)、C6(图片形变)、C8(PDF 文本层)、C9(整页图片化/可编辑性)均**不能由我给终判**;本文的 C3/C5 结论是"渲染像素证据 + 目视",不是断言器结论。
2. **p8 的 1.61:1** 与 **p9 的 ≈8–9pt** 是**能由渲染像素确证**的(前者有逐行最深像素与直方图,后者有三项独立比值),故按"严重"报出;但它们的**意图**(占位灰?降级灰?字号配置错页?)无法从渲染判断。
3. **绝对字号**:全部 pt 值为 ±1pt 估算(CJK 字体的墨高/字宽比未标定);**跨页/同页比值**为精确值。
4. **非视觉项**:内容正确性、页序(本稿页序未发现异常)、作者签名项(L3 的元数据、隐藏页、批注、字体替换风险)不在目检范围。
5. **JPEG 伪影**:源图为已转码 JPEG;所有阈值取 1–2px 余量,结论仅采用远大于伪影量级的差异(最小报告差异 = 0.10in / 19 个 RGB 级)。

## 6. 总判定

**不可按现状交付(有阻断项)。**
- 阻断 1:第 8 页 9 条说明文字对比度 **1.61:1**(C5 硬阈值 4.5:1,且同版式 p4 为 5.41:1)——一句话可复现:把 p8 的说明文字色改回 #5F6B7C 级别。
- 阻断 2:第 9 页正文 **≈8–9pt**,低于 C3 的 10pt 下限,且比同页图注还小(层级倒挂)——把 p9 的 bullet 字号恢复到 p6 档(≈16pt)即解。
- 修完这 2 项后,余下 13 项(10 轻微 + 3 候选)不阻断交付,但建议至少处理 #3/#4/#5(第 3 页整页灰底 + 卡片 1.04:1 对比 + 卡片底部空)与 #10(浅色页标题比正文内缩 0.10–0.14in)——这三处是"整页观感"级差异,投影环境下会被看见。
